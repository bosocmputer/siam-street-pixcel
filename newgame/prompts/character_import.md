# เอาโมเดลตัวละครจากโปรแกรมอื่นเข้าเกม

เกมใช้ตัวละครได้ 2 แบบ ไม่ต้องแก้โค้ด แก้แค่รายการใน `apps/citywalk/public/assets.json`

## แบบที่ 1: ตรงสเปกของเกม (เหมือนตัวที่ผมสร้าง)

ชื่อข้อต่อตาม `packages/rpg-core/config/rig.json` ชิ้นร่างกายแข็งติดข้อต่อ ตรวจด้วย
`pnpm --filter @newgame/rpg-core check-model <ไฟล์.glb>` ใส่ในรายการได้เลย:

```json
{ "id": "hero_m", "file": "models/hero_m.glb" }
```

## แบบที่ 2: จากโปรแกรมปั้นโมเดล (Blender, VRoid Studio, Mixamo ฯลฯ)

ส่งออกเป็น `.glb` (glTF binary) ที่มีโครงกระดูก (skinned mesh) ได้เลย **ไม่ต้องมีท่าทาง** เกมขยับเองด้วยโค้ด
แล้วบอกเกมว่ากระดูกชื่ออะไร:

```json
{
  "id": "hero_m",
  "file": "models/hero_m.glb",
  "joints": "mixamo",
  "restFix": { "UpperArm_L": [0, 0, -90], "UpperArm_R": [0, 0, 90] }
}
```

| ช่อง | ใส่อะไร |
|---|---|
| `joints` | `"mixamo"` (กระดูกชื่อ mixamorig:...) หรือ `"vroid"` (J_Bip_...) หรือตารางเอง `{ "Hips": "pelvis", "Head": "head", ... }` ชื่อซ้ายคือชื่อใน rig.json ขวาคือชื่อในไฟล์ |
| `restFix` | ถ้าโมเดลยืนกางแขน (T-pose) ใส่ตามตัวอย่างเพื่อเอาแขนลง ถ้ายืนแขนแนบตัวอยู่แล้ว ไม่ต้องใส่ |
| `forward` | ถ้าโมเดลไม่ได้หันไปทาง +Z: `"-z"`, `"+x"` หรือ `"-x"` (VRoid แบบ VRM 0.x มักเป็น `"-z"`) |
| `height` | ความสูงเป็นเมตร ถ้าไม่ใส่ใช้ 1.70 (เกมย่อขยายให้เอง ไฟล์เป็นเซนติเมตรก็ได้) |
| `outline` | `false` ถ้าไม่อยากได้เส้นขอบตัว · `outlineWidth` ความหนาเส้นเป็นเมตร (ค่าเริ่ม 0.006) |

ข้อควรรู้
- ใช้ได้กับโมเดลที่มีกระดูกคนครบ: สะโพก กระดูกสันหลัง อก คอ หัว ไหล่ ต้นแขน ปลายแขน มือ ต้นขา หน้าแข้ง เท้า (ข้อไหนไม่มี ข้อนั้นก็ไม่ขยับ)
- งบสำหรับมือถือ: ไม่เกิน 10,000 สามเหลี่ยม ไฟล์ไม่เกิน 1 MB (ไฟล์ใหญ่กว่านี้ใช้ได้ แต่อาจกระตุกบนมือถือรุ่นเก่า)
- จุดที่ลูกพลังเกิด: ใส่โหนดเปล่าชื่อ `Socket_Hand_R` ที่กลางฝ่ามือขวา ถ้าไม่มี เกมใช้ข้อมือขวาแทน
- ทดสอบแล้วกับไฟล์จำลองแบบ Mixamo (ชื่อกระดูก Mixamo + T-pose + หน่วยเซนติเมตร) ยังไม่เคยลองกับไฟล์จริงจาก Blender หรือ VRoid ส่งมาเมื่อไหร่ผมตรวจให้
