## 0.1 ภาพ pixel ของคนและมอน

ตั้งแต่ 19 ต.ค. 2569 เกมใช้แบบ pixel 3D เป็นหลัก: ทั้งฉาก คน และมอนเป็นโมเดล 3D วาดเป็นเม็ด pixel ทั้งจอ (1 เม็ด = 2 จุดบนจอ ตั้งที่ `scenePixel`) จึงต้องการแค่โมเดล .glb ไม่ต้องมีภาพทีละท่า ภาพ pixel แบนด้านล่างยังใช้ได้ด้วย `?art=pixel`

ภาพ pixel แบน (`?art=pixel`) ได้มา 2 ทาง ใช้ปนกันได้

| ทาง | ทำยังไง | สถานะ |
|---|---|---|
| วาดจากโมเดล 3D ในเกม | เกมถ่ายโมเดล .glb ทุกท่า 5 ทิศ แล้วย่อเป็น pixel ตอนโหลด (ค่าใน `config/sprites.json`) ใช้กับทุกตัวที่ไม่มีไฟล์ภาพ | ✅ ผู้เล่น สไลม์ 4 ชนิด บอส |
| ไฟล์ภาพจาก PixelLab หรือวาดเอง | รวมภาพด้วย `apps/citywalk/tools/sprites/pack.py` แล้วใส่ชื่อใน `assets.json` ช่อง `sprites` (ดู `prompts/sprite_import.md`) | ⬜ รอผู้สร้างเลือก |

| เรื่อง | กติกา |
|---|---|
| ทิศ | 8 ทิศ หรือ 5 ทิศ (หน้า เฉียงหน้า ข้าง เฉียงหลัง หลัง แล้วเกมกลับด้านให้) |
| ท่าผู้เล่น | `idle` (ต้องมี) `walk` `run` `cast` `hurt` `down` `ride` ท่าที่ไม่มีใช้ท่าใกล้เคียง |
| ท่ามอน | ชื่อเดียวกับท่าในโมเดล (`Idle` `Jumping` `Squishing` `Attacking` ...) |
| ขนาด | ไม่ต้องตรงกัน บอกความสูงจริงตอนรวมภาพ เกมย่อขยายให้ |
| เลือกแบบภาพ | ท้ายลิงก์ใส่ `?art=pixel3d` (หลัก) · `?art=pixel` (ภาพแบน) · `?art=3d` (3D เรียบ) เกมจำไว้ |
| หน้าจอ | ฟอนต์ pixel ไทย (GNU Unifont, OFL) ไอคอนวาดเป็นจุดในโค้ด กรอบ ปุ่ม แถบเลือด เป็น pixel ทั้งหมด เมือง (แผนที่) เป็น 3D วาดเป็นเม็ด pixel |
| มอน | กะพริบตา (ภาพตาปิดวาดตอนโหลด) ยืดหดตอนกระโดด/ลงพื้น หายใจตอนยืน มีบทพูดในกล่องคำพูดและเครื่องหมายเหนือหัว (! โกรธ เหงื่อ มึน โน้ต) |
