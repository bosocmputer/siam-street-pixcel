# Old City · นักดาบฝึกหัด

ต้นแบบโลก 3D เมืองเก่าเชียงใหม่ เดินตามถนนและซอยจริงภายในกรอบคูเมือง
พร้อมแนวถนนรอบนอก มุมสูง และแผนที่ย่อไม่มีชื่อสถานที่หรือหมุด
เริ่มเป็นนักดาบมุมมองบุคคลที่หนึ่ง สู้กับสไลม์ 3 ตัวที่ลานประตูฝั่งตะวันออก

## เปิดฉาก

ใช้ Node.js 22+ และ pnpm 10.28.0 จาก root repository:

```sh
pnpm install
pnpm dev:world
```

เปิด URL ที่ Vite แสดง (ค่าเริ่มต้น `http://localhost:4317/`) และกด
“เริ่มต่อสู้” ใช้ WASD เพื่อเดิน ลากเมาส์เพื่อมอง Shift วิ่ง F/คลิกซ้ายฟันดาบ
และ Q/คลิกขวาค้างเพื่อตั้งรับ กด P เพื่อพัก M เปิดแผนที่ V สลับมุมสูง
กด E รวมพลังวิญญาณที่ดาบแล้วปล่อยคลื่นจันทร์เสี้ยวโจมตีระยะไกล
มือถือใช้วงควบคุมซ้าย ลากฉากด้านขวา และปุ่มฟัน/ตั้งรับ
สไลม์เตือนก่อนโจมตี ฆ่าแล้วได้ XP และเกิดใหม่ใน 8 วินาที ตายแล้วเริ่มใหม่ได้

```sh
pnpm test:world
pnpm build:world
```

อ่าน [รายละเอียดและข้อจำกัดของฉาก](apps/chiangmai-world/README.md)
และ [บันทึกงาน/วิธีตรวจรับ](docs/chiangmai_world_walk.md)
