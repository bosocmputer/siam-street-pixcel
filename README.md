# Chiang Mai Old City Walk

ต้นแบบโลก 3D เมืองเก่าเชียงใหม่ เดินตามถนนและซอยจริงภายในกรอบคูเมือง
พร้อมแนวถนนรอบนอก มุมสูง แผนที่ย่อ และจุดสำรวจสำคัญ 9 แห่ง

## เปิดฉาก

ใช้ Node.js 22+ และ pnpm 10.28.0 จาก root repository:

```sh
pnpm install
pnpm dev:world
```

เปิด URL ที่ Vite แสดง (ค่าเริ่มต้น `http://localhost:4317/`) และกด
“ลงไปเดินที่ประตูท่าแพ” ใช้ WASD หรือลูกศรเพื่อเดิน ลากเมาส์เพื่อมอง และ Shift เพื่อวิ่ง
มือถือใช้วงควบคุมซ้ายและลากฉากด้านขวา

```sh
pnpm test:world
pnpm build:world
```

อ่าน [รายละเอียดและข้อจำกัดของฉาก](apps/chiangmai-world/README.md)
และ [บันทึกงาน/วิธีตรวจรับ](docs/chiangmai_world_walk.md)
