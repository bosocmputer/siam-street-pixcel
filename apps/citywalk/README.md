# เดินเมืองเก่าเชียงใหม่ (ตัวเกม)

ตัวเกม 3D บนแผนที่จริง: เดินในคูเมืองเชียงใหม่และรอบนอก มีสไลม์และสกิลทดสอบ สมองเกม (ตรรกะและตัวเลข) อยู่ที่ `packages/rpg-core` ไฟล์นี้เป็นส่วนแสดงผล

- ข้อมูล: OpenStreetMap ดึงด้วย `tools/fetch_osm.sh` แปลงด้วย `pnpm data` (`tools/osm_to_world.py`) ได้ `public/world.json`
- เครดิตที่ต้องแสดง: © OpenStreetMap contributors (ODbL)
- รัน: `pnpm dev` · เทสต์: `pnpm test` และ `pnpm e2e` (`?debug=1` เปิด `window.__walk` ให้เทสต์)
- ไฟล์ที่โหลดตอนเริ่ม: `public/assets.json` (แผนที่ + model พร้อมชื่อท่าทางที่ต้องมี) โหลดพร้อมตัวเลขความคืบหน้า model ไหนโหลดไม่ได้จะข้ามไปใช้ของชั่วคราว (`src/assets.ts`)
- โครงไฟล์: `src/main.ts` ต่อทุกส่วนเข้าด้วยกัน · `src/ui/` หน้าจอ (HUD, ปุ่มสกิล) · `src/input.ts` ปุ่มกด → คำสั่ง (คีย์ตั้งใน `rpg-core/config/controls.json`) · `src/storage.ts` เซฟในเครื่อง · `src/walker.ts` ตัวละครชั่วคราว
- เกมเดินเป็นก้าวคงที่ 1/60 วินาที หยุดเมื่อสลับไปแอปอื่น เซฟตำแหน่งและการตั้งค่าทุก 5 วินาทีและตอนออก
- ประตูท่าแพ: โมเดลของผู้สร้าง `public/models/thaphae_gate.glb` ปรับแค่ตำแหน่ง ทิศ และขนาดให้เข้ากับช่องกำแพงในแผนที่ (`src/gateModel.ts`)
- ลานท่าแพ: สร้างด้วยโค้ดจากข้อมูลแผนที่ (`src/plaza.ts`, `src/plazaShape.ts`) วิ่งระหว่างปลายคูน้ำสองข้างและยื่นถึงขอบถนน มีขอบหิน ทางเท้า และทางม้าลาย
- สไลม์: โมเดลของผู้สร้าง `public/models/slime_aquanaut.glb` ใช้ท่าทางในไฟล์ (Idle, Jumping, Squishing, Attacking) สมองอยู่ที่ `rpg-core/src/slimeBrain.ts` ตัวเลขที่ `rpg-core/config/monsters.json`
- สกิลทดสอบ (กระสุนไฟ/กระสุนน้ำ): รวมพลังที่มือก่อน แล้วพุ่งตรงไปหาเป้า ไฟระเบิดวงกว้างโดนสไลม์รอบ ๆ ด้วย ตัวเลขอยู่ที่ `rpg-core/config/skills.json` เอฟเฟกต์ทั้งหมดวาดด้วยโค้ดใน `src/fx.ts` ปุ่มสกิลเป็นตำแหน่งชั่วคราวเพื่อทดสอบ ยังไม่ใช่หน้าจอจริง
- ผู้เล่น: เลือด พลัง เลเวล ค่าประสบการณ์ (`rpg-core/config/player.json`) สกิลใช้พลัง ชนะสไลม์ได้ค่าประสบการณ์ เลือดหมดจะล้ม 3 วินาทีแล้วฟื้นที่จุดพักหน้าประตูท่าแพ ไม่เสียอะไร แผงสถานะอยู่ที่ `src/ui/playerHud.ts`
- สไลม์ที่โดนตีจะโกรธ 8 วินาที ไล่ตามและกระแทก (ตัวเลขใน `rpg-core/config/monsters.json` หัวข้อ attack และ anger) ตัวที่ไม่โกรธแค่ขู่ ไม่ทำเจ็บ
- วัดและศาสนสถานเป็นฉากหลังเท่านั้น ไม่มีการต่อสู้
