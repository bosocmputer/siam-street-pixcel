# เดินเมืองเก่าเชียงใหม่ (ตัวเกม)

ตัวเกม 3D บนแผนที่จริง: เดินในคูเมืองเชียงใหม่และรอบนอก มีสไลม์และสกิลทดสอบ สมองเกม (ตรรกะและตัวเลข) อยู่ที่ `packages/rpg-core` ไฟล์นี้เป็นส่วนแสดงผล

- ข้อมูล: OpenStreetMap ดึงด้วย `tools/fetch_osm.sh` แปลงด้วย `pnpm data` (`tools/osm_to_world.py`) ได้ `public/world.json`
- เครดิตที่ต้องแสดง: © OpenStreetMap contributors (ODbL)
- รัน: `pnpm dev` · เทสต์: `pnpm test` และ `pnpm e2e` (`?debug=1` เปิด `window.__walk` ให้เทสต์)
- ไฟล์ที่โหลดตอนเริ่ม: `public/assets.json` (แผนที่ + model พร้อมชื่อท่าทางที่ต้องมี) โหลดพร้อมตัวเลขความคืบหน้า model ไหนโหลดไม่ได้จะข้ามไปใช้ของชั่วคราว (`src/assets.ts`)
- โครงไฟล์: `src/main.ts` ต่อทุกส่วนเข้าด้วยกัน · `src/ui/` หน้าจอ (HUD, ปุ่มสกิล) · `src/input.ts` ปุ่มกด → คำสั่ง (คีย์ตั้งใน `rpg-core/config/controls.json`) · `src/storage.ts` เซฟในเครื่อง · `src/walker.ts` ตัวละครชั่วคราว
- เกมเดินเป็นก้าวคงที่ 1/60 วินาที หยุดเมื่อสลับไปแอปอื่น เซฟตำแหน่งและการตั้งค่าทุก 5 วินาทีและตอนออก
- ประตูท่าแพ: โมเดลของผู้สร้าง `public/models/thaphae_gate.glb` ปรับแค่ตำแหน่ง ทิศ และขนาดให้เข้ากับช่องกำแพงในแผนที่ (`src/gateModel.ts`)
- ลานท่าแพ: สร้างด้วยโค้ดจากข้อมูลแผนที่ (`src/plaza.ts`, `src/plazaShape.ts`) วิ่งระหว่างปลายคูน้ำสองข้างและยื่นถึงขอบถนน มีขอบหิน ทางเท้า และทางม้าลาย
- สไลม์: โมเดลของผู้สร้าง `public/models/slime_aquanaut.glb` ใช้ท่าทางในไฟล์ (Idle, Jumping, Squishing, Attacking) สมองอยู่ที่ `rpg-core/src/slimeBrain.ts` ตัวเลขที่ `rpg-core/config/monsters.json`
- สกิลทดสอบ (กระสุนไฟ/กระสุนน้ำ): รวมพลังที่มือก่อน แล้วพุ่งตรงไปหาเป้า ไฟระเบิดวงกว้างโดนสไลม์รอบ ๆ ด้วย ตัวเลขอยู่ที่ `rpg-core/config/skills.json` เอฟเฟกต์ทั้งหมดวาดด้วยโค้ดใน `src/fx.ts` ตามภาพ ref ของผู้สร้าง: ลูกบอลมีเกลียวหมุนข้างใน หางแบบดาวหางเรียวแหลม ไฟกระทบแล้วเปลวพุ่งขึ้น ระเบิดเป็นโดม พื้นแตกร้าว เศษหินกระเด็น น้ำกระทบแล้วพุ่งเป็นเสา สาดเป็นมงกุฎ มีวงคลื่นสีฟ้าบนพื้น (`e2e/effects.spec.ts` ถ่ายภาพทีละขั้นจากด้านข้างไว้เทียบ) ปุ่มสกิลเป็นตำแหน่งชั่วคราวเพื่อทดสอบ ยังไม่ใช่หน้าจอจริง
- ผู้เล่น: เลือด พลัง เลเวล ค่าประสบการณ์ (`rpg-core/config/player.json`) สกิลใช้พลัง ชนะสไลม์ได้ค่าประสบการณ์ เลือดหมดจะล้ม 3 วินาทีแล้วฟื้นที่จุดพักหน้าประตูท่าแพ ไม่เสียอะไร แผงสถานะอยู่ที่ `src/ui/playerHud.ts`
- สไลม์ที่โดนตีจะโกรธ 8 วินาที ไล่ตามและกระแทก (ตัวเลขใน `rpg-core/config/monsters.json` หัวข้อ attack และ anger) ตัวที่ไม่โกรธแค่ขู่ ไม่ทำเจ็บ
- สไลม์ 4 แบบ (น้ำ ไฟ ยักษ์ จิ๋ว): ใช้ model ตัวเดียว เปลี่ยนสีตัว ขนาด ความเร็วท่า ระยะก้าว เลือด ความแรง และจุดอ่อนธาตุด้วยข้อมูลใน `rpg-core/config/monsters.json` (แต่ละแบบเขียนเฉพาะส่วนที่ต่างจาก base) จุดเกิดอยู่ที่ `config/spawns.json` พิกัดอิงที่ประตูท่าแพ ห้ามให้มอนเกิดในวัดหรือศาสนสถาน
- บอส (ราชาสไลม์กระแสน้ำ): โมเดลของผู้สร้าง `public/models/slime_tide_regent.glb` (id `tide_regent` ใน `assets.json`) ใช้ท่าเดิมของสไลม์ (Idle, Jumping, Squishing, Attacking) บวกท่าใหม่ 2 ท่า: `Boss_Tidal_Charge` (ย่อตัวเล็ง แล้วพุ่งชนเป็นเส้นตรง) และ `Boss_Ground_Slam` (ยกแขนแล้วกระแทกพื้น โดนทุกคนในวง) ตัวเลขทั้งหมดอยู่ที่ `rpg-core/config/monsters.json` หัวข้อ `boss_tide_regent` (เลือด 500 แพ้ไฟ ต้านน้ำ ถูกตีแล้วขยับน้อย) กติกาท่าพิเศษอยู่ที่ `rpg-core/src/slimeBrain.ts` ใช้เฉพาะตอนโกรธ (ถูกตีแล้ว): ใกล้ใช้กระแทกพื้น ห่างหน่อยใช้พุ่งชน แต่ละท่ามีเวลาพัก มอนอื่นใส่ท่าพิเศษได้เหมือนกันโดยเขียนในข้อมูลล้วน ๆ จุดเกิดบอสอยู่ใน `config/spawns.json` เกิดใหม่หลังถูกล้ม 2 นาที
- ของตก: ตารางของตกอยู่ในแต่ละแบบของมอน ตัวของอยู่ที่ `config/items.json` (`color`, `size`, `model`) ของที่ตกลอยออก รอ 0.6 วินาที แล้วลอยเข้าหาตัวเมื่อเดินใกล้ (`src/pickups.ts`) ของที่ไม่เก็บหายไปใน 30 วินาที กระเป๋าเก็บในเซฟ (เวอร์ชัน 3) **เมื่อมี model ของจริง:** ใส่ไฟล์ใน `public/models/` เพิ่มรายการใน `public/assets.json` แล้วใส่ id นั้นในช่อง `model` ของของชิ้นนั้น ของบนพื้นจะเปลี่ยนเป็น model ที่ปรับขนาดให้เองตาม `size` (`src/itemModels.ts`) ยังไม่มีตัวนับของบนจอ ตอนเก็บจะแจ้งเป็นข้อความเด้ง
- กล้อง: 2 แบบ สลับได้ที่ปุ่ม "กล้อง" แบบเริ่มต้นคือเฉียงไหล่ (ตัวละครอยู่ค่อนซ้าย เหลือกลางจอไว้เล็ง) มีล็อกเป้านุ่ม ๆ ตอนยืนนิ่งหรือกำลังร่าย กล้องค่อย ๆ หันหาเป้า ตัวเลขอยู่ที่ `rpg-core/config/camera.json`
- วัดและศาสนสถานเป็นฉากหลังเท่านั้น ไม่มีการต่อสู้
- เสียง: ทุกเสียงสังเคราะห์ด้วยโค้ด (Web Audio) สูตรอยู่ที่ `rpg-core/config/sounds.json` (ชั้นเสียงคลื่น/เสียงซ่า + ซองความดัง + ตัวกรอง + เสียงสั่นหมุนวน (`wobble`) + ความแตกพร่า (`drive`) + ความดัง/ลำดับความสำคัญ/คูลดาวน์) กติกา (จำกัด 16 เสียง ขโมยช่องตามลำดับ เสียงเตือนกดเสียงอื่น ซ้าย-ขวา/ไกล-ใกล้ ก้าวเท้า คอมโบเก็บของ) เป็นฟังก์ชันล้วนที่ `rpg-core/src/audioMath.ts` ส่วนเล่นจริงอยู่ที่ `src/audio/` (`engine.ts`, `synth.ts`) เสียงสกิลแบ่งเป็น รวมพลัง → ปล่อย → พุ่ง → กระทบ: ไฟเสียงต่ำ หนัก แตกพร่า (มีเสียงคำราม `fire.flight` ที่ดังค้างจนลูกไฟถึงเป้า เป็นเสียงแบบ `held`) น้ำเสียงสูง เร็ว คม เสียงเริ่มได้หลังแตะครั้งแรกเท่านั้น (มือถือบังคับ) ปุ่ม "เสียง" บนแถบชิปเปิด/ปิด เก็บแยกจากเซฟ (`citywalk.sound`) จึงไม่หายตอนเริ่มใหม่
- เสียงให้เข้ากับภาพ: เสียงกระทบตามเวลาของภาพ (เศษหินตกลง 0.4–0.9 วิ, น้ำตกกลับ 0.4–1.1 วิ, ไฟที่ยังไหม้บนพื้น) ดังจากจุดที่ระเบิดจริง ระเบิดใหญ่ได้ยินไกลกว่า (`reach`) เสียงพุ่งของลูกไฟตามลูกไฟไป มีเสียงก้องของถนนระหว่างกำแพง (`space`) เสียงโดนจุดอ่อนและสไลม์เจ็บ/ละลายเป็นเสียงจริงจัง (แตก ฉ่า ซ่า) ไม่ใช่เสียงกระดิ่งการ์ตูน
- ห้องฟังเสียง: ลิงก์ "ฟังเสียงทั้งหมด" ในหน้าแรก (หรือใส่ `#sounds` ท้ายลิงก์) กดฟังทีละเสียง หรือกด "ฟังต่อกันทั้งชุด" ของแต่ละสกิลเพื่อฟังตามจังหวะในเกม เลือกซ้าย/กลาง/ขวา ดูภาพความถี่ของแต่ละเสียง (`src/audio/soundLab.ts`) เทสต์เรียก `__walk.sound.measure(id)` เพื่อวัดความดัง/ความยาว/การแตกพร่าโดยไม่ต้องเล่นจริง
- **เปลี่ยนเป็นไฟล์เสียงจริงทีหลัง:** รหัสเสียงคงเดิม เกมเรียกด้วยรหัสเท่านั้น (`sound.play('fire.impact')`) จึงเปลี่ยนด้านในได้โดยไม่แตะที่อื่น ไฟล์สำหรับ iPhone แนะนำ mp3 หรือ m4a ผู้สร้างยังไม่ได้ฟังเสียงจริง ความดังตั้งจากการวัดคลื่น ไม่ใช่จากหู เพลงประกอบและเสียงบรรยากาศเมืองยังไม่ทำ
