# Old City Swordsman

## สิ่งที่ทำได้

- ดูภาพรวมเมืองและหมุน/ซูม/เลื่อนมุมกล้อง
- ลงเดินระดับสายตาตามถนนและตรอกจริง พร้อมชนอาคาร กำแพง และคูน้ำ
- ข้ามคูเมืองตามทางที่มีข้อมูลถนน/ทางเดิน ไม่เดินทะลุน้ำโดยอิสระ
- เล่นนักดาบมุมมองบุคคลที่หนึ่ง เห็นแขน ถุงมือ และดาบพร้อมท่าฟัน/ตั้งรับ
- ต่อสู้กับสไลม์ 3 ตัวบริเวณลานประตูฝั่งตะวันออก สไลม์เดินเข้าหาและเตือนก่อนโจมตี
- ดาบมีระยะ มุมฟัน คูลดาวน์ ความอึด และตรวจแนวกำแพงก่อนทำความเสียหาย
- ตั้งรับด้านหน้าลดความเสียหาย แสดงเลือดทั้งสองฝ่าย ตัวเลขดาเมจ และเอฟเฟกต์เมื่อโดน
- ฆ่าได้ 20 XP ครบ 60 XP ขึ้น Lv.2 เพิ่มเลือด/ดาเมจ สไลม์เกิดใหม่ใน 8 วินาที
- มีพักเกม ตาย/เริ่มใหม่ และพักอัตโนมัติเมื่อออกจากหน้าจอ เปิดแผนที่ หรือดูมุมสูง
- แผนที่ย่อหันเหนือ ไม่มีชื่อสถานที่ ชื่อถนน หรือหมุด POI ในหน้าจอเล่น
- ขยายแผนที่แล้วคลิกย้ายตำแหน่ง ระบบหาที่ว่างใกล้เคียงถ้าตรงกับอาคาร
- แสงเช้า/เย็น คุณภาพภาพสองระดับ วิธีเล่น และปุ่มเต็มหน้าจอ
- ใช้คีย์บอร์ด/เมาส์บนคอม หรือวงควบคุมและลากมองบนมือถือ

## คำสั่ง

จาก root: `pnpm dev:world`, `pnpm test:world`, `pnpm build:world`

จาก directory นี้:

```sh
pnpm dev
pnpm typecheck
pnpm test
pnpm build
pnpm preview
pnpm data:import
```

`data:import` ใช้ cache ใน `.cache/old-city-osm.json` ถ้ามี หากต้องการ snapshot ใหม่
ให้ย้ายไฟล์ cache เดิมออกไปเก็บก่อน แล้วเรียกใหม่ คำสั่งดึงข้อมูลครั้งเดียวแบบจำกัดขอบเขต
ตัวเกมไม่ยิง query ไป Overpass ทุกครั้งที่เปิดฉาก เปลี่ยน endpoint ได้ด้วย `OSM_ENDPOINT`

## โครงสร้าง

- `src/geo.ts`: พิกัดเป็นเมตร การชน และ spatial grid
- `src/world.ts`: mesh ถนน น้ำ อาคาร กำแพง ต้นไม้ และสถานที่สำคัญ
- `src/main.ts`: กล้อง แสง ตัวควบคุม การย้ายจุด และ HUD
- `src/minimap.ts`: แผนที่ถนนจริงและตำแหน่งผู้เล่น
- `src/combat.ts`: simulation ต่อสู้แบบ deterministic แยกจากการเรนเดอร์
- `src/combat-view.ts`: โมเดลดาบ แขน สไลม์ แอนิเมชัน และเอฟเฟกต์การต่อสู้
- `tools/import-osm.mjs`: ดึงและแปลง snapshot
- `tests/`: ทดสอบการฉายพิกัด ทางข้ามน้ำ พื้นที่ชน และข้อมูลจริง

## ขอบเขตและความแม่นยำ

ขอบเขตนำเข้า: 18.7778–18.8012 N, 98.9740–98.9960 E ครอบคลุมคูเมืองและพื้นที่ขอบนอก
สเกลโลกใช้เมตร โดย X ไปตะวันออก Z ไปใต้ และ Y ขึ้น พื้นฉากเป็นระนาบ
snapshot วันที่ 15 ตุลาคม 2569 มีอาคาร 8,808 รูปทรง ถนน/ทางเดิน 2,034 ช่วง
ข้อมูลน้ำ 53 รายการ และจุดข้อมูล 2,784 จุด จำนวนนี้รวมพื้นที่รอบกรอบคูเมืองด้วย

353 รูปทรงอาคารมีค่า height หรือ building:levels ใน OSM ที่นำเข้า ที่เหลือประเมินชั้น
อย่างคงที่จาก ID รายละเอียดหน้าต่าง ประตู หลังคา กันสาด และเฟอร์นิเจอร์ไม่ได้สำรวจจริง
สีอาคารใน snapshot ยังไม่ได้ใช้เป็นสี facade รายหลัง โมเดลสถานที่สำคัญเป็นรูปแบบจำลอง
บางส่วนของต้นไม้ใช้พิกัดจริง แต่ต้นไม้ริมถนน/เสาไฟอีกส่วนสร้างเสริม ภูเขาตะวันตกเป็นฉากหลัง
ไม่มี DEM และไม่ได้รับรองว่าทุกซอยหรืออาคารใน OSM มีข้อมูลครบเท่ากัน

การต่อสู้เป็น real-time ต้นแบบในเครื่อง ไม่มีเซิร์ฟเวอร์ ไม่มีการบันทึกความคืบหน้า
โหลดหน้าใหม่แล้วเริ่มใหม่ทั้งหมด เมื่อพัฒนาออนไลน์ต้องย้าย simulation และการตรวจความเสียหาย
ไปฝั่งเซิร์ฟเวอร์ก่อน ไม่ควรเชื่อผลจาก client

ควบคุม: WASD เดิน, Shift วิ่ง, F/คลิกซ้ายฟัน, Q/คลิกขวาค้างตั้งรับ,
P พัก, M แผนที่, V มุมสูง, Esc ปล่อยเมาส์และพัก การตั้งรับบนมือถือเป็นปุ่มกดเปิด/ปิด

ยังเข้าอาคารหรือขึ้นบันไดไม่ได้ ไม่มีรถ/คนจากสถานที่จริง ไม่มีภาพ Google Maps หรือ
ภาพดาวเทียมที่นำมาเป็น texture และไม่มีการจำลองผู้เล่นออนไลน์

## ประสิทธิภาพ

รวม geometry ตามวัสดุและพื้นที่ ใช้ instancing สำหรับของซ้ำ และแสดงหน้าต่าง/กันสาด
เฉพาะระยะใกล้ เงาระยะใกล้เปิดเฉพาะโหมดเดิน จำกัด pixel ratio และมีโหมดประหยัด
ผล FPS ต้องระบุเครื่อง/viewport และใช้เป็นผลเฉพาะการทดลอง ไม่รับประกันทุกมือถือ
