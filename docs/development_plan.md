## 0. กติกาการทำงาน (สำคัญ อ่านก่อนเริ่ม)

1. **ทำทีละ milestone ตามลำดับ** แต่ละ milestone จบด้วย commit ที่ CI ผ่าน และอัปเดตสถานะในไฟล์นี้ (หัวข้อ 9)
2. **ห้ามเปลี่ยนข้อที่ GDD ระบุว่า “ตัดสินแล้ว”** ถ้าเห็นว่าควรเปลี่ยน ให้หยุดและถามผู้สร้าง
3. **ตัวเลขสมดุลทั้งหมดอยู่ใน `packages/game-core/config/*.json`** ห้ามฝังตัวเลขในโค้ด
4. **ข้อความที่ผู้เล่นเห็นทั้งหมดอยู่ใน `apps/web/src/i18n/th.json`** และต้องตรงกับน้ำเสียงและศัพท์ใน GDD ข้อ 2
5. **เซิร์ฟเวอร์เป็นผู้ตัดสินผลทุกอย่าง** client ห้ามส่งผลลัพธ์ (ของที่ได้ ดาเมจ เหรียญ) มาให้เซิร์ฟเวอร์เชื่อ
6. **ทุกฟังก์ชันใน `game-core` ต้องมี unit test** และต้อง deterministic (ไม่ใช้ `Math.random()` หรือ `Date.now()` ข้างใน)
7. **จุดหยุดถามผู้สร้าง** (ห้ามข้าม): ก่อนใช้ PixelLab generation เป็นชุด, ก่อน deploy สาธารณะ, ก่อนเปิด playtest, เมื่อผลจำลองสมดุลไม่เข้าเป้า, เมื่อต้องจ่ายเงินค่าบริการใด ๆ
8. **ห้าม commit secret** (PixelLab token, Supabase service key) ใช้ environment variable เท่านั้น
9. pin เวอร์ชัน dependency แบบแน่นอน และ commit lockfile
10. รายงานผลตามจริง: ถ้าเทสต์ไม่ผ่านหรือข้ามขั้นไหน ให้เขียนไว้ในสถานะ milestone

### M1.3 ค่าสมดุล (ปรับแล้วจากผลจำลอง — ค่าจริงอยู่ใน `packages/game-core/config/balance.json`)

สูตรที่ใช้จริง (ตัวเลขสุดท้ายอยู่ใน config):

```
HP        = (50 + VIT*12 + level*8 + item.hp) * (1 + passive.hp) * bestiary
ATK       = (5 + STR*2 + level*1.5 + item.atk) * (1 + passive.atk) * bestiary
DEF       = (VIT*1 + item.def) * (1 + passive.def) * combo * weapon.defMult
atkPerSec = min(3, (1 + AGI*0.02) * (1 + passive.speed) * combo * weapon.speed)
crit      = min(0.5, 0.05 + AGI*0.004 + skill/combo/charm bonus), critDmg = 1.5
skillPow  = 1 + INT*0.03          cdr = min(0.3, INT*0.005)
expToNext = 62 * level^1.86       (เวล 1–9 คูณ 0.026 ให้เซสชันแรกรู้สึกเร็ว)
monsterHP(eff)  = base.hp  * (1 + 0.42*(eff-1))^2.07
monsterATK(eff) = base.atk * (1 + 0.36*(eff-1))^1.07
eff = stage + district.stageOffset        (ในเวียง 0 · ริมปิง 30 · ท่าแพ 60 · นิมมาน 90)
killsForStage   = 270 * killMult * 1.12^(stage-1)   (killMult 1 / 1.6 / 2.4 / 3.4)
kill cycle      = เวลาฆ่า + 6.4 วินาที
idleCap         = 10 ชม.
```

สิ่งที่เปลี่ยนจากร่างแรกในแผนนี้ และเหตุผล (จากผลจำลอง):

- **ความยากมอนต่อเนื่องเป็นเส้นเดียวทั้ง 4 ย่าน** (`stageOffset`) แทนตัวคูณต่อย่าน เพราะตัวคูณทำให้ย่านหลัง ๆ ถูกเคลียร์ในวันเดียว
- **มอนโตแบบพหุนาม** ไม่ใช่เอกซ์โปเนนเชียล เพราะพลังผู้เล่นโตแบบพหุนามตามเลเวล เอกซ์โปเนนเชียลทำให้ติดกำแพงที่ด่าน ~28 ตลอด
- **ดูดเลือดช่วยได้สูงสุด 60%** ของดาเมจที่เข้ามา ไม่งั้นสกิลดูดเลือดทำให้อมตะ
- **ด่านต้องใช้จำนวนฆ่าเพิ่มตามด่าน** และ **ความคืบหน้าด่านเก็บแยกต่อย่าน** (สลับไปเก็บสกิลย่านอื่นไม่เสียความคืบหน้า)
- **เวลารอเกิดมอน 6.4 วินาที**: เมื่อตั้งต่ำกว่านี้ เกมเร็วเกินไป เมื่อตั้งสูงกว่านี้ บิลด์ไม่มีผลต่อความเร็ว (วัดด้วย "ผู้เล่นไม่แตะสกิล/ของ" เทียบกับผู้เล่นปกติ)
- **ระบบที่เพิ่มหลังเห็นกราฟรอบแรก** (แก้ 3 ปัญหา: ทางเลือกหมดก่อนเลเวล, ช่วงราบกลางเกม, ผู้เล่นเปิดนาน ๆ ที):
  **ตื่นพลัง** (แก่นเกินเลเวลสูงสุดเติมเกจ แล้วเลือกให้สกิลวิวัฒน์), **หมุดหมายด่าน** (ของการันตีทุก 5 ด่าน), **พลังสะสมนอกเวลา** (เวลาเกินเพดานนับ 30% อีกไม่เกิน 24 ชม.), **มอนทอง** (ลุ้นโชคระหว่างฟาร์ม) ทั้งหมดอยู่ใน `claim`/`absorb`/`awaken` ของ `game-core` พร้อมเทสต์
- **ย่านเรา** เก็บในสถานะผู้เล่น ทุกคนเริ่มฟาร์มในเวียง แก่นสกิลบทเรียนแรกมาจากย่านเรา และร่างขั้นแรกเปิดตามธาตุที่กลืนมากสุด + ธาตุย่านเรา

## M5 — ระบบสังคมขั้น 1
