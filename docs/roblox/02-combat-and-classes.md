# 02 — ระบบ Action Combat อาชีพ และสกิล

[สารบัญ](README.md) · [ระบบ RPG](03-rpg-and-social-systems.md)

สถานะ: ข้อเสนอและค่าทดลอง ไม่มีระบบนี้ใน Roblox แล้วในขณะเขียน

## 1. หลักการควบคุม

แอ็กชันเรียลไทม์ บุคคลที่สาม เห็นตัวละคร อาวุธ และพื้นเตือนชัด ไม่ผลัดกันเดิน ไม่ต้องเลือกมอนก่อนฟัน ใช้ตัวช่วยเล็งแบบอ่อนและตัวเลือกล็อกเป้าบอส มุมมองบุคคลที่หนึ่งเป็นทางเลือกภายหลัง

| การกระทำ         | PC ค่าตั้งต้น   | มือถือ             | ผล                             |
| ---------------- | --------------- | ------------------ | ------------------------------ |
| เดิน/มอง         | WASD / เมาส์    | จอยซ้าย / ลากขวา   | ทิศเคลื่อนและมุมกล้องแยกได้    |
| โจมตีปกติ        | คลิกซ้าย        | ปุ่มใหญ่ขวา        | คอมโบสามจังหวะ กดต่อได้        |
| ตั้งรับ          | F ค้าง          | ปุ่มโล่ค้าง        | ลดดาเมจจากด้านหน้า ใช้ stamina |
| หลบ              | Q               | ปุ่มหลบ            | ขยับสั้น มีช่วงหลบการโจมตี     |
| คลื่นคมจันทร์    | E ค้างแล้วปล่อย | ปุ่มสกิลค้าง/ปล่อย | ชาร์จแล้วปล่อยคลื่น            |
| โต้ตอบ/ช่วยคนล้ม | R               | ปุ่มบริบท          | ไม่ใช้ปุ่มเดียวกับฟัน          |
| สลับล็อกเป้า     | Tab             | ปุ่มเป้าขนาดเล็ก   | ไม่บังคับใช้ในมอนทั่วไป        |

คีย์เปลี่ยนได้ภายหลัง ปุ่มเพิ่มอาชีพอื่นเปิดตามความคืบหน้า MVP มีสกิลกดหลักเพียงหนึ่งปุ่มนอกเหนือโจมตี/รับ/หลบ ไม่แสดง hotbar สิบช่องว่าง

## 2. จังหวะการต่อสู้

การโจมตีแบ่งเป็นเตรียม → ช่วงโดน → คืนท่า แต่ละท่าระบุเวลายกเลิกให้หลบหรือตั้งรับ ไม่เปิดให้ cancel ทุกเฟรมจนแอนิเมชันไร้ความหมาย

| ค่าทดสอบเลเวล 1              | ค่าเสนอ                                                                                             |
| ---------------------------- | --------------------------------------------------------------------------------------------------- |
| HP / stamina / spirit สูงสุด | 120 / 100 / 100                                                                                     |
| ความเร็วเดิน / วิ่ง          | 16 / 22 studs ต่อวินาที                                                                             |
| ดาเมจคอมโบพื้นฐาน            | 12 → 14 → 20                                                                                        |
| ระยะฟัน                      | 7 studs ตรวจรูปทรงและผนัง                                                                           |
| หลบ                          | 12 studs ใน 0.35 วินาที ใช้ stamina 25                                                              |
| ช่วงไม่รับดาเมจจากหลบ        | 0.18 วินาที เริ่มหลังยืนยัน action                                                                  |
| ฟื้น stamina                 | 20 ต่อวินาที หลังไม่ใช้ 0.8 วินาที                                                                  |
| ตั้งรับ                      | ลดดาเมจ 70% ในกรวยด้านหน้า 120 องศา                                                                 |
| stamina เมื่อรับโดน          | ใช้ `max(12, incomingDamage × 0.8)`; ไม่พอให้ guard break 0.6 วินาทีและรับดาเมจส่วนที่ป้องกันไม่ได้ |
| ตั้งรับตรงจังหวะ             | หน้าต่างเริ่ม 0.18 วินาที ใช้เป็นโบนัส ไม่จำเป็นต่อการจบเกม                                         |
| ฟื้น spirit                  | 8 ต่อวินาที หลังไม่ใช้ 1 วินาที                                                                     |

หน่วยตำแหน่งใช้ studs ตลอดฝั่ง combat แปลงจากเมตรเฉพาะ pipeline แผนที่ ดู [หน่วยและแผนที่](04-real-world-map.md) ค่าความเร็วและ hitbox ต้องปรับตามขนาด avatar จริง ไม่ลอกค่าจากเว็บเก่า

## 3. สถานะตัวละครและข้อห้ามซ้อนท่า

สถานะหลัก: Idle, Moving, Attacking, Guarding, Dodging, Charging, Staggered, Downed, Respawning

- Charging เดินช้าลง ไม่ฟันธรรมดาพร้อมกัน; ยกเลิกด้วยหลบได้ก่อนปล่อย
- Dodging ไม่เริ่มโจมตีใหม่จนพ้นช่วงล็อก; ไม่ให้กดรัวข้าม stamina
- Staggered ต้องสั้นและมีช่วงกัน stun ต่อเนื่อง; บอสไม่ถูกสตันถาวรจากผู้เล่นหลายคน
- Downed ทำดาเมจไม่ได้ ช่วยเพื่อนได้ภายในเวลาจำกัด
- ตาย/ออกเกม/ย้ายฉากต้องปิด hitbox และ projectile ที่หมดสิทธิ์ทันที

client เล่นภาพตอบสนองล่วงหน้าได้ แต่ HP ผลโดน และรางวัลให้เซิร์ฟเวอร์ตัดสินตาม [แนวทางความปลอดภัย Roblox](https://create.roblox.com/docs/scripting/security/client-server-boundary)

## 4. สกิลเอกลักษณ์: คลื่นคมจันทร์

สกิลต้นฉบับใช้อารมณ์ “อาวุธสะสมพลังแล้วปล่อยคมโค้ง” ไม่ใช้ชื่อ ท่า เสียง หรือรูปลักษณ์เฉพาะของผลงานอื่น

| ส่วน                         | ค่าทดลอง                                                   |
| ---------------------------- | ---------------------------------------------------------- |
| ID                           | skill.sword.crescent                                       |
| เปิดใช้                      | จบ Q002                                                    |
| ชาร์จขั้นต่ำ/เต็ม/ค้างสูงสุด | 0.25 / 0.9 / 1.5 วินาที                                    |
| spirit / cooldown            | 35 / 6 วินาที เริ่มเมื่อปล่อยสำเร็จ                        |
| ระยะ/ความเร็วคลื่น           | 90 studs / 100 studs ต่อวินาที                             |
| ดาเมจที่ชาร์จเต็ม            | 40 ก่อนปรับพลังอุปกรณ์                                     |
| ทะลุ                         | ศัตรูสูงสุด 4 ตัว แต่โดนแต่ละตัวได้ครั้งเดียวต่อ cast      |
| สิ่งกีดขวาง                  | หยุดที่ผนัง/พื้น ไม่ผ่านกำแพง                              |
| ยกเลิกก่อนปล่อย              | ไม่เสีย spirit และไม่สร้าง projectile; มี input rate limit |
| ถ้าปล่อยเร็วเกินขั้นต่ำ      | ยกเลิก ไม่เปลี่ยนเป็นโจมตีฟรี                              |

ภาพตามลำดับ: เส้นแสงไหลเข้ามือและคมดาบ → ขอบดาบสว่างพร้อมเสียงชาร์จไต่ขึ้น → ฟันปล่อยคลื่นรูปจันทร์เสี้ยว → ชนแล้วแตกเป็นเศษแสง แสงลดตามระยะ ไม่ยิงแฟลชเต็มจอ

server จำเวลาเริ่มชาร์จ ตรวจสถานะ spirit cooldown ทิศทาง และระยะก่อนสร้างผลโดน ข้อความ client ว่า “ชาร์จเต็มแล้ว” ไม่มีสิทธิ์เพิ่มดาเมจเอง คลื่นใช้ sweep/raycast ระหว่างตำแหน่งเก่าใหม่ ลดปัญหาวิ่งข้ามศัตรูเมื่อเฟรมตก

### ทางเลือกหลัง MVP

เลือกได้หนึ่งเทคนิค: **คมกว้าง** เพิ่มความกว้างลดระยะ / **คมสวน** เพิ่มพลังเมื่อรับตรงจังหวะ / **คมคืนพลัง** คืน spirit บางส่วนเมื่อโดนหลายเป้า ตัวเลขและความคุ้มค่าต้องเทียบกัน ไม่เปิดสามอันพร้อมกันจนกลายเป็นเพิ่มพลังทุกทาง

## 5. อาชีพและอาวุธ

ตัวละครหนึ่งฝึกหลายอาวุธได้ เปลี่ยนชุดได้ที่จุดพักนอกต่อสู้ ความชำนาญแยกตามอาวุธ ไม่เสียเงินเพื่อเปลี่ยน และไม่ผูกกับงานจริงของผู้เล่น

| ชุดอาวุธ              | บทบาท                 | เอกลักษณ์                                      | สถานะ            |
| --------------------- | --------------------- | ---------------------------------------------- | ---------------- |
| นักดาบ                | ระยะประชิดยืดหยุ่น    | คอมโบ รับจังหวะ คลื่นคมจันทร์                  | MVP              |
| ผู้พิทักษ์: โล่และหอก | ป้องกัน/เปิดจังหวะ    | กันแนวหน้า ผลัก และย้ายความสนใจมอน             | หลัง MVP ลำดับ 1 |
| ผู้ใช้พลัง: คทาสะท้อน | ระยะไกล/ควบคุม        | วางเขตพลัง เปลี่ยนทิศศัตรู                     | หลัง MVP ลำดับ 2 |
| นักธนู                | ยิงเคลื่อนที่/จุดอ่อน | เล็งจุดอ่อน ผูกเป้าให้เพื่อน                   | ระยะขยาย         |
| ผู้ประสานเสียง        | สนับสนุน/ฟื้นฟู       | จังหวะเกราะและเยียวยา ไม่ใช่ยืนกดฮีลอย่างเดียว | ระยะขยาย         |

ทุกอาชีพต้องเล่นเควสต์หลักคนเดียวได้ ไม่บังคับรอ healer หรือ tank เพื่อทำเนื้อเรื่องเริ่มต้น ดันเจียนใช้กลไกที่แบ่งหน้าที่ตามสถานการณ์ได้

HP เป็นฐานหนึ่งผู้เล่นที่ค่าสถานะเริ่มต้น; เลเวล โหมดเควสต์ และ scaling ปรับเพิ่มผ่าน config การจบเนื้อเรื่องไม่บังคับใส่ของหายาก

มอนแต่ละตัวมี home, leash, target, phase และ encounterId กลับบ้านแล้วเลือดคืนโดยไม่ลากเข้าเขตพัก เป้าหมายค้าง/หาเส้นทางไม่เจอให้ reset ตามกติกา ไม่ทะลุกำแพงมาโจมตี

## 7. บอส: ผู้เฝ้าไร้หน้า

| ช่วง           | กลไก                             | ผู้เล่นตอบอย่างไร                              |
| -------------- | -------------------------------- | ---------------------------------------------- |
| HP 100–65%     | กวาดคมเป็นกรวย มีแสงและท่าเตือน  | หลบข้างหรือตั้งรับ แล้วตีช่วงพัก               |
| HP 65–30%      | เรียกสมอ 2 จุด และสไลม์ไม่เกินงบ | แบ่งคนกดสมอ/คุมมอน; เดี่ยวกดต่อกันได้          |
| HP ต่ำกว่า 30% | ยิงแนวคลื่นสลับ มีช่องปลอดภัย    | อ่านช่อง แล้วใช้คลื่นตัดแก่นเพื่อเปิดช่วงโจมตี |

ทุกท่าต้องอ่านได้ทั้งจากสี รูปทรง และเสียง ถ้าคนหลุดไม่ทำให้กลไกค้าง ไม่มีท่าบังคับต้องมีสี่คนพร้อมกัน ระยะเวลาบอสเป้า 3–5 นาทีในเควสต์ Q006

สูตร HP ปาร์ตี้เริ่มทดลอง: `baseHP × (1 + 0.65 × (N - 1))`, N = 1–4 ล็อก N ตอนเปิดรอบ; ไม่เพิ่มดาเมจตาม N โดยอัตโนมัติ คนหลุดยังกลับได้ภายในเวลาที่กำหนด หากออกถาวรให้เสนอเริ่มรอบใหม่โดยไม่หักทรัพยากร

## 8. การโดนและความยุติธรรม

- หนึ่ง swing/cast มี ID เดียวและชุดเป้าหมายที่โดนแล้ว ไม่โดนซ้ำตามจำนวนชิ้นส่วนร่างกาย
- ตรวจอยู่ใน encounter/ชั้นเดียวกัน ระยะ มุม และกำแพงก่อนหักเลือด
- เก็บเวลาเซิร์ฟเวอร์สำหรับ cooldown; ค่าคลาดเคลื่อน latency ต้องมีเพดานและวัดจริง ไม่ให้ client ย้อนเวลาไม่จำกัด
- หลบต้องตอบสนองไวทางภาพ แต่เซิร์ฟเวอร์แก้สถานะได้ บอกผู้เล่นอย่างนุ่มนวลเมื่อคำสั่งถูกปฏิเสธ
- ปรับให้ PvE เล่นได้เมื่อ ping สูง ไม่แก้ด้วยการยอมรับทุก hit จาก client

## 9. แพ้และช่วยเพื่อน

ในปาร์ตี้ HP หมดเป็น Downed 15 วินาที เพื่อนช่วยต่อเนื่อง 3 วินาทีได้หนึ่งครั้งต่อ encounter จากนั้นแพ้กลับสมอด้วย HP เต็ม ไม่เสียเลเวล ไม่ทำของแตก ไม่ขายชุบชีวิตใน MVP

คนเดียวเลือกเริ่มใหม่ได้ทันที บอส reset แต่เควสต์ส่วนที่ผ่านแล้วและรางวัลที่บันทึกสำเร็จไม่หาย จุดกลับมาไม่อยู่ในวงโจมตี

## 10. เกณฑ์รับงาน

คนใหม่โจมตี ตั้งรับ หลบ และปล่อยสกิลได้หลัง tutorial; มือถือมองเห็นพื้นเตือน; กล้องไม่ติดผนัง; คลื่นไม่ผ่านกำแพง; มอนเดียวรับดาเมจหนึ่งครั้งต่อ cast; ปาร์ตี้ไม่กักบอสด้วย stun; กดรัวไม่ทำ spirit ติดลบ; หลุด/ตายกลางชาร์จไม่เกิดคลื่นค้าง; ไม่มีผลโดนในเขตพัก

การเช็กความรู้สึกต้องมีผู้เล่นจริง การทดสอบอัตโนมัติยืนยันกติกาได้แต่ตัดสินความสนุกแทนผู้เล่นไม่ได้
