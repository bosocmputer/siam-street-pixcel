# 01 — โลก เนื้อเรื่อง และเควสต์

[สารบัญ](README.md) · [GDD](../../game_design_document.md)

สถานะ: ข้อเสนอสร้างสรรค์สำหรับพิจารณา เรื่องราวเป็นเรื่องแต่ง ไม่ใช่ประวัติศาสตร์หรือความเชื่อที่อ้างว่าเป็นของชุมชนเชียงใหม่

## 1. แกนเรื่อง: สถานที่จำเราได้

ทุกสถานที่มี “รอยสะท้อน” จากสิ่งที่ผู้คนทำซ้ำ ทั้งการรอเพื่อน เปิดร้าน เดินกลับบ้าน และสัญญาที่ยังทำไม่สำเร็จ ปกติรอยเหล่านี้ไม่มีรูปร่าง แต่คืนหนึ่งเครือข่ายที่เรียกว่า Atlas ตื่นขึ้น ทำให้รอยสะท้อนซ้อนกับโลกจริง

ผู้เล่นเป็นหนึ่งใน “ผู้ประสาน” คนธรรมดาที่เห็นโลกทั้งสองด้านและยึดรอยสะท้อนให้อยู่ทรงได้ อาวุธเป็นเครื่องมือที่รับจังหวะของผู้ใช้ ใครก็ฝึกดาบ คทา หรือโล่ได้ ไม่ผูกกับอาชีพจริงหรือชาติกำเนิด

เริ่มเชียงใหม่เพราะเครือข่ายส่วนแรกที่เข้าถึงได้เปิดอยู่ที่นี่ ไม่อ้างว่าเมืองนี้เป็นต้นกำเนิดทุกวัฒนธรรม เมื่อขยายโลก แต่ละเมืองมีผู้คน ความทรงจำ และวิธีแก้ปัญหาของตัวเอง

## 2. กฎโลกที่ใช้สร้างเกม

| คำ         | ความหมาย                            | ผลต่อ gameplay                         |
| ---------- | ----------------------------------- | -------------------------------------- |
| โลกฐาน     | เมืองอ้างอิงเส้นทางจริง             | เดินทาง นัดเพื่อน พัก และสำรวจ         |
| รอยซ้อน    | พื้นที่จำกัดที่เรื่องแต่งแทรกเข้ามา | ต่อสู้ เปลี่ยนรูปได้โดยไม่บิดแผนที่ฐาน |
| แก่นสะท้อน | พลังที่รอยซ้อนรวมตัว                | วัตถุดิบและเป้าหมายกิจกรรม             |
| สมอ        | อุปกรณ์ตรึงรอยซ้อน                  | ป้องกันหรือเปิดทางในเควสต์             |
| Atlas      | เครือข่ายความทรงจำของสถานที่        | เหตุผลของการเดินทางข้ามเมือง           |
| เสียงว่าง  | รอยสะท้อนที่ถูกตัดจากความหมายเดิม   | ต้นเหตุศัตรู ไม่ใช่กลุ่มคนจริง         |

รอยซ้อนต้องมีขอบเขตและทางออก การปิดรอยซ้อนไม่ทำลายเมืองจริง ตัวละครที่แพ้ถูกสมอดึงกลับ ไม่ต้องมีเงื่อนไขตายจริงหรือติดในเกม ประตูเปลี่ยนเมืองทำงานเป็นเครือข่าย ไม่จำลองทั้งโลกพร้อมกัน

## 3. น้ำเสียงและการเล่า

ตื่นเต้นจากการค้นพบ อบอุ่นจากชุมชน และลึกลับพอให้ตามต่อ การต่อสู้มีพลังและจังหวะ ไม่เน้นเลือด NPC มีปัญหาที่เข้าใจได้ ไม่อ่านบทสนทนายาวก่อนให้เล่น

เล่าด้วยภาพก่อนข้อความ: เงาประตูขยับผิดทิศ หยดน้ำลอยขึ้น เสียงเรียกดังจากตรอกว่าง ผู้เล่นกดข้ามแล้วกลับมาอ่านบันทึกได้ ข้อความใช้ key แปลภาษาแยกจากระบบ

## 4. ตัวละครสำคัญ

ทุกตัวเป็นงานแต่ง ไม่อ้างอิงบุคคลจริงโดยไม่ได้รับอนุญาต รูปร่าง อาวุธ และชื่อสกิลต้องออกแบบเอง ไม่ยืมภาพจำเฉพาะจากอนิเมะหรือเกมอื่น

## 5. ฉากเปิด

ผู้เล่นเข้ามาที่ทางเดินชั้นรอยซ้อนใกล้ประตูท่าแพ ได้ยินเสียงเหรียญตกแต่ไม่เห็นเหรียญ เงากำแพงแยกเป็นเส้นสีน้ำเงิน เมษาบอกให้ถอยจากหยดฝนที่กำลังลอยขึ้น

ผู้เล่นเดิน หยิบดาบฝึก และตีสไลม์ตัวแรก จึงค่อยรู้ชื่อโลกและเมนูที่จำเป็น ไม่ต้องเลือกเผ่า ค่าสเตตัส และสิบอาชีพก่อนสัมผัสเกม

ประโยคเปิดเรื่อง: “ถ้าได้ยินเมืองเรียก อย่าตอบคนเดียว”

Q005–Q006 เป็นรอยซ้อนสั้นในพื้นที่แยกภายใน Place เดิม MVP เปิดได้หนึ่งรอบต่อเซิร์ฟเวอร์สำหรับคนเดียวหรือปาร์ตี้ หากมีคนใช้ให้เข้าคิวและกลับทำกิจกรรมเมืองได้ ไม่สร้างสำเนาไม่จำกัด

### ตอนจบบทนำ

ผู้เฝ้าไม่ได้เฝ้าประตูเพื่อกันเราเข้า มันกัน “แผนที่ที่ไม่มีคนอยู่” ไม่ให้ออกมา เครื่อง Atlas ส่งพิกัดที่สอง นนท์จำได้ว่าพิกัดนั้นไม่ใช่เชียงใหม่ แต่ยังเข้าไม่ได้

กลับมาทางเดิม แสงสมอเปลี่ยน เมษาซ่อมของ ผู้เล่นอื่นเดินผ่าน โลกดำเนินต่อหลังจบเควสต์ ไม่ตัดเป็นหน้าจอจบเกม

## 7. โครงเรื่องซีซันแรก หลัง MVP

ซีซันคือแพ็กเนื้อเรื่อง ไม่กำหนดรอบขาย battle pass หรือตารางอัปเดตจนรู้กำลังผลิต

### บท 1 — เสียงในกำแพง

ตามชิ้นส่วนสมอที่ถูกย้ายอย่างมีเจตนา ผู้เล่นเลือกช่วยเปิดทางหรือซ่อมจุดพักก่อน ทำให้เส้นทางและบทสนทนาต่าง ไม่แบ่งเซิร์ฟเวอร์เป็นประวัติศาสตร์คนละชุด

ฉากเด่น: ถนนในรอยซ้อนซ้ำสามครั้ง ต้องอ่านของที่เปลี่ยนไปและแบ่งงาน ไม่ใช่เขาวงกตสุ่มยาว ๆ

### บท 2 — ตลาดของสิ่งที่ไม่เคยเกิด

ตลาดสมมติขายของที่เจ้าของ “เกือบได้เป็น” เช่น ดาบของคนที่ไม่เคยออกเดินทาง ผู้เก็บหน้าว่างเสนอความปลอดภัยแลกความทรงจำ ผู้เล่นสงสัยว่าอาวุธและเลเวลมาจากใคร

ฉากเด่น: เลือกหนึ่งในสองพลังยืมใช้เฉพาะรอบดันเจียน เล่นซ้ำลองอีกแบบได้ ไม่ทำให้อุปกรณ์ถาวรหาย

### บท 3 — คืนที่เมืองเงียบ

เสียงและสีหายจากชั้นรอยซ้อน ทีมคืนจังหวะเมืองผ่านหลายจุด คนไม่เก่งต่อสู้ช่วยขนแก่นหรือเปิดสมอได้ มีเควสต์ส่วนตัวให้ตามทันโดยไม่รอคนเต็ม

ฉากเด่น: ชนะแล้วแสงกลับไปตามถนนที่เคยเดิน มีการ์ดผู้ช่วยในรอบนั้น เริ่มจากสถานะเซิร์ฟเวอร์ชั่วคราว ไม่อ้างว่าเปลี่ยนทุกเซิร์ฟเวอร์ทั่วโลก

### บท 4 — แผนที่ที่ไม่มีชื่อ

Atlas เก็บรักษาสถานที่ผ่านแบบจำลอง แต่เริ่มลบความแตกต่างเพื่อซ่อมความเสียหาย ผู้เก็บหน้าว่างเป็นกลไกป้องกันที่เชื่อคำสั่งเดิมจนลืมเหตุผล

ผู้เล่นทำให้ระบบยอมรับว่าสถานที่มีชีวิตเพราะเปลี่ยนได้ บอสสลับรูปแบบตามสมอที่เปิด ไม่มีตัวเลือกเสียเงินเพื่อจบดี จบแล้วเปิดสถานีทางไกลสู่เมืองใหม่ เลือกเมืองเมื่อข้อมูลและกำลังผลิตพร้อม ไม่ประกาศวันเปิดไว้ล่วงหน้า

## 8. เล่นซ้ำโดยไม่ยืดงาน

- รอบแรกเล่าครบ รอบต่อไปย่อบทและมีบันทึกย้อนหลัง
- ของใช้งานหลักรับแน่นอน ของแต่งและความชำนาญเป็นแรงจูงใจต่อ ไม่ซ่อนตอนจบหลังดรอปหายาก
- เหตุการณ์สุ่มจากรูปแบบที่ออกแบบและตรวจแล้ว ไม่สร้างฉาก AI สดทุกครั้ง
- ความลับมีเบาะแส ไม่บังคับเล่นกลางดึกหรือยืนร้านสปอนเซอร์
- สมุดแยกเรื่องแต่งจากข้อมูลสถานที่จริงที่ต้องมีแหล่งอ้างอิง

## 9. ตัวอย่างข้อมูลเควสต์

```yaml
id: Q002
titleKey: quest.q002.title
prerequisite: Q001.completed
steps:
  - id: learn_response
    objective: defend_or_dodge_telegraphed_attack
    count: 2
  - id: return_hit
    objective: hit_enemy_after_successful_response
    count: 2
rewardId: reward.q002.first_clear
repeatable: false
```

เป็น schema เสนอ ไม่ใช่ config ที่รันได้แล้ว ความสำเร็จมาจากเซิร์ฟเวอร์ ไม่ให้ client ส่งว่าเควสต์จบเอง การตั้งรับหรือหลบผ่านได้ทั้งสองทางเพื่อลดการติดด่านสอน

## 10. เกณฑ์รับงานเนื้อเรื่อง

ทุกเควสต์มีข้อความรับ/ส่ง เป้าหมาย เงื่อนไขกลับเข้าร่วม รางวัลที่อ้าง catalog และรายการภาพ/เสียง ผู้เล่นข้ามบทแล้วยังรู้ว่าจะไปไหน เล่นกับเพื่อนต่างขั้นได้ และรับรางวัลซ้ำจากการออกเข้าไม่ได้

ผู้เล่นไม่ต้องรู้ตำนานท้องถิ่นจึงเข้าใจเรื่อง สถานที่จริงไม่ถูกนำไปกล่าวอ้างเรื่องแต่งเป็นข้อเท็จจริง
