## กติกาการอ่าน

- **ข้อกำหนดผู้สร้าง:** มาจากบทสนทนา เช่น เริ่มเชียงใหม่ เป้าหมายทั่วโลก บทบาทเลือกอิสระ ไม่บังคับบุคคลที่หนึ่ง
- **ข้อเสนอ:** สิ่งที่ออกแบบเพิ่มให้พิจารณา เปลี่ยนได้หลังอ่าน
- **ค่าทดลอง:** balance, ขนาดฉาก, งบแอสเซ็ต และจำนวนผู้เล่นที่ต้องวัดจริง
- **MVP:** รุ่นเล็กที่เล่นจบรอบได้ ไม่ใช่ทุกระบบในความฝัน
- **หลัง MVP:** มีแบบไว้ ยังไม่อยู่ในงานสร้างรอบแรก
- **ข้อมูลแพลตฟอร์ม:** อ้างเอกสารทางการ ตรวจอีกครั้งเมื่อเริ่ม implementation

## ลำดับความสำคัญ

1. ต่อสู้สนุกและควบคุมง่าย
2. เพื่อนเข้าเล่นด้วยกันได้และข้อมูลไม่หาย
3. พื้นที่เล็กมีคุณภาพและกลิ่นอายของเชียงใหม่
4. เครื่องผู้เล่นเป้าหมายรับไหว
5. ค่อยเพิ่มเนื้อหา อาชีพ เมือง และกิจกรรมระยะยาว

คำว่า MMORPG เป็นวิสัยทัศน์ของโลกที่มีตัวละครเติบโตและหลายชุมชน ส่วน MVP เป็น Action RPG ออนไลน์ขนาดเล็ก ไม่อ้างว่ารองรับคนจำนวนมากในฉากเดียวแล้ว

## สำหรับ AI ที่มาทำต่อ

อ่าน GDD → 06 → 07 และเอกสารของระบบที่จะทำ อย่าอ่านข้อเสนอทุกอันเป็นคำสั่งให้สร้างทั้งหมด ให้หยิบ milestone ถัดไปหนึ่งช่วง ตรวจสถานะจริงใน Studio และบันทึกหลักฐานก่อนเปลี่ยนงานเป็นเสร็จ

งานเว็บเดิมใน repository เป็น legacy แยกจาก Roblox โดยเฉพาะ Three.js, Phaser, PixelLab, first-person บังคับ และแผน idle เดิม ไม่ใช่ข้อกำหนดของเกมใหม่นี้
