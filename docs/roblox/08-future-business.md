# 08 — รายได้ ร้านจริง และกิจกรรม: แผนอนาคต

[สารบัญ](README.md) · [การตัดสินใจและแหล่งข้อมูล](09-decisions-and-sources.md)

สถานะ: ผู้สร้างมีวิสัยทัศน์ธุรกิจนี้ แต่พักไว้ก่อน ยังไม่พัฒนาหรือเปิดขายใน MVP ไม่มีราคา รายได้ หรือจำนวนลูกค้าที่พิสูจน์แล้ว

## 1. ภาพธุรกิจที่เข้าใจจากผู้สร้าง

เกมเติบโตจากเมืองจริง ผู้ประกอบการอาจซื้อบริการสร้างหน้าร้านในตำแหน่งเดียวกับของจริง พร้อมป้ายและกิจกรรมในเกม ผู้เล่นเห็นแบรนด์ขณะสนุกกับโลก ไม่จำเป็นต้องเดินทางไปหน้าร้านจริง และไม่เปิดเผย GPS ส่วนตัว

รายได้สินค้าในเกมอีกเส้นหนึ่งมาจากของแต่งที่ผู้เล่นอยากใช้แสดงตัวตน ไม่ผูกกับความได้เปรียบเหนือคนไม่จ่าย

## 2. สินค้าในเกมที่เสนอเมื่อเกมพร้อม

สกินดาบที่ไม่เปลี่ยน hitbox/ระยะ, ชุดแต่ง, ท่าทาง, เอฟเฟกต์ภาพที่อ่านง่ายและปิดลดได้, ธีมพื้นที่พัก หรือแพ็กสนับสนุนที่บอกของชัดเจน ไม่มีอาวุธแรงกว่าจากการจ่าย ไม่มีการสุ่มเสียเงินในแผนแรก

ของถาวรและของซื้อซ้ำต้องเลือกชนิดผลิตภัณฑ์ของ Roblox ให้ตรงการใช้งาน ระบบ developer product ต้องยืนยันและบันทึกธุรกรรมฝั่ง server ผ่าน ProcessReceipt ตาม [Developer Products](https://create.roblox.com/docs/production/monetization/developer-products) การป้องกันให้ของซ้ำและการกู้คืนเป็นงานที่ต้องออกแบบ/ทดสอบก่อนเปิดเงินจริง

ไม่ระบุส่วนแบ่งรายได้ ค่าแลกเงิน หรือรายได้สุทธิในฉบับนี้ เพราะต้องตรวจเงื่อนไขบัญชี ประเทศ ภาษี และแพลตฟอร์มในวันที่จะทำจริง

## 3. ร้านจริงในโลกเกม

| ส่วน          | สิ่งที่อาจให้บริการ              | เงื่อนไข                                                 |
| ------------- | -------------------------------- | -------------------------------------------------------- |
| โมเดลหน้าร้าน | อาคารและ facade อ้างอิงภาพร้าน   | สิทธิ์ภาพ แบรนด์ และการอนุมัติครบ                        |
| ป้ายสนับสนุน  | พื้นที่ที่เห็นชัดและระบุว่าโฆษณา | ผ่านขั้นตอนที่แพลตฟอร์มกำหนด                             |
| กิจกรรมร้าน   | มินิเกมหรือจุดพบเพื่อน           | สมัครใจ และมีประสบการณ์เทียบเท่าให้คนที่เห็นแบรนด์ไม่ได้ |
| ของแต่งร่วม   | ลายหรือ item cosmetic            | ไม่เพิ่มพลังต่อสู้และตรวจสิทธิ์                          |
| รายงานผล      | ผู้เข้าร่วมและ engagement รวม    | ไม่ส่งข้อมูลส่วนตัวหรือ GPS ให้ร้าน                      |

ไม่ขายสิทธิ์ผูกขาดถนน ยึดร้านคู่แข่ง หรือรับประกันยอดขายหน้าร้านจากจำนวนคนในเกม ไม่สร้างตัวเลข impression เองโดยเรียกมันว่ามาตรฐานการวัดของ Roblox

## 4. ข้อจำกัดสำคัญที่ต้องทบทวนก่อนขายโฆษณา

แผนร้านจริงแบบมีแบรนด์อาจเข้าข่าย advertising integration ต้องตรวจการจัดประเภทกับ Roblox ก่อนเปิดให้ผู้เล่นเห็น มาตรฐานที่ตรวจวันที่ 2026-10-15 ระบุการส่ง asset แคมเปญให้ตรวจ/อนุมัติ การจำกัดผู้มีสิทธิ์เห็น การเปิดเผยว่าเป็นโฆษณา และข้อจำกัดลิงก์/QR ออกแพลตฟอร์ม ดู [Advertising Standards](https://en.help.roblox.com/hc/en-us/articles/13722260778260-Advertising-Standards)

ดังนั้น “รับเงินร้านแล้ววางโลโก้ให้ทุกคนเห็น” ไม่ใช่ขั้นตอนที่ยืนยันว่าใช้ได้ ต้องออกแบบรุ่นไม่มีแบรนด์และกติกาการแสดงผลตามสิทธิ์ด้วย โฆษณาที่ Roblox จัดส่งผ่าน Immersive Ads เป็นอีกระบบ มี eligibility ของเกม/บัญชีและผู้ชม ไม่เท่ากับขายโมเดลร้านโดยตรง ดู [Immersive ads](https://create.roblox.com/docs/production/monetization/immersive-ads)

PolicyService มีเครื่องมือด้าน eligibility รวมถึง CanViewBrandProjectAsync ในเอกสารที่ตรวจ แต่ต้องใช้ให้ตรงโปรแกรมและการลงทะเบียนจริง ไม่ hardcode อายุหรือใช้ API ผิดวัตถุประสงค์เพื่อข้ามข้อจำกัด ดู [PolicyService](https://create.roblox.com/docs/reference/engine/classes/PolicyService)

ข้อกำหนดด้านนโยบายอาจเปลี่ยน ต้องตรวจใหม่เมื่อถึง milestone นี้ เอกสารฉบับนี้ไม่ได้ยืนยันว่าธุรกิจพร้อมอนุมัติหรือให้ข้อสรุปกฎหมายสำหรับประเทศใด

## 5. ตัวอย่างกิจกรรมที่ออกแบบไว้

ร้านกาแฟที่ได้รับอนุญาตเป็นพื้นที่พักในเกม เปิดกิจกรรม “จังหวะชงแสง” ผู้เล่นช่วยเรียงแก่นสีให้ได้เสียงเพลง รับของแต่งตามกติกาที่ผ่านการตรวจ ผู้เล่นที่ไม่มีสิทธิ์เห็นแบรนด์ได้ฉากร้านสมมติและเล่นวงจรที่เหมาะสม ไม่ทำป้ายโฆษณาเป็นทางผ่านบังคับของเควสต์หลัก

ตัวอย่างเป็นแนวทางออกแบบ ยังไม่ยืนยันว่าแจกของในกิจกรรมโฆษณารูปแบบนี้ได้รับอนุญาต ต้องตรวจข้อจำกัดการให้รางวัลและ audience ก่อน ไม่เริ่มติดตามคูปองหรือผลการซื้อของจริงใน MVP

## 6. สิ่งที่ต้องเรียนรู้ก่อนคิดราคา

ต้นทุนผลิต/แก้โมเดลหนึ่งร้าน, การดูแลเมื่อร้านเปลี่ยนหน้าตา, จำนวนผู้เล่นที่มีสิทธิ์เห็นจริง, ต้นทุนรายงานผล, ขั้นตอนตรวจแคมเปญ และอัตราคนเล่นกิจกรรมโดยสมัครใจ

เริ่มทดลองกับร้านจำนวนเล็กเมื่อฐานเกมผ่าน ไม่เปิดแพ็กโฆษณาทั่วโลกก่อนรู้ว่าร้านหนึ่งต้องใช้เวลาและขั้นตอนเท่าไร กำหนดวิธีถอดแบรนด์เมื่อแคมเปญหมดหรือร้านยกเลิกโดยไม่ทำแผนที่/เควสต์พัง
