# 09 — การตัดสินใจ สมมติฐาน ความเสี่ยง และแหล่งข้อมูล

[สารบัญ](README.md) · [สถานะส่งต่อ](../coordination/STATUS.md)

วันที่จัดทำ/ตรวจเอกสารทางการ: 2026-10-15 ข้อมูลแพลตฟอร์มอาจเปลี่ยน ไม่มีงานสำรวจตลาดหรือ benchmark ใหม่ที่อ้างว่าทำสำเร็จในรอบนี้

## 1. บันทึกความต้องการที่ยืนยันจากบทสนทนา

- โลกอ้างอิงแผนที่จริง เป้าหมายทั่วโลก เริ่มเชียงใหม่และค่อยขยาย
- ผู้เล่นเลือกบทบาทในเกมอิสระ ไม่ผูกกับอาชีพจริง
- มุมมองบุคคลที่หนึ่งไม่จำเป็น
- ผู้สร้างไม่มีพื้นฐาน Roblox และต้องการให้ AI ช่วยทำ implementation
- งานเว็บและแนวเดิมยกเลิกแล้ว ให้ทำแนวทาง Roblox ใหม่
- แผนสินค้าในเกมและโฆษณาร้านจริงเก็บไว้เป็นอนาคต
- รอบนี้ให้คิดเอกสารพัฒนา เนื้อเรื่อง ระบบ asset และ Action MMORPG พร้อมส่งต่อ Codex/Claude ผ่าน repo

## 3. สมมติฐานเสี่ยงและวิธีพิสูจน์

| สมมติฐาน                        | ความเสี่ยง                              | การทดสอบที่ควรทำก่อนลงทุนเพิ่ม                                             |
| ------------------------------- | --------------------------------------- | -------------------------------------------------------------------------- |
| คนอยากสู้ในเมืองอ้างอิงจริง     | เมืองไม่ได้ช่วยความสนุก                 | เทียบพฤติกรรมใน graybox กับฉากเมืองเล็กและถามเหตุผลหลังเล่น                |
| AI สร้างงานได้ในคุณภาพที่รับได้ | ทำ demo ได้แต่แก้ซ้ำยาก                 | จบ R00–R02 และเก็บเวลารวมการแก้/ตรวจ                                       |
| ต้นทุนทำเมืองขยายซ้ำได้         | landmark ทุกจุดกลายเป็นงานเฉพาะ         | ผลิตเซลล์สองที่ใช้ kit เดิมแล้วเทียบ effort                                |
| มือถือรับ art และ combat ได้    | ปุ่ม เอฟเฟกต์ หรือ streaming ขวางเกม    | เครื่องจริงใน scenario เดียวกับ PC                                         |
| ปาร์ตี้ต่างเลเวลสนุก            | รุ่นพี่แบกหมดหรือรู้สึกถูกลดพลังเกินไป  | ให้คู่ต่างเลเวลเล่นแล้วดู contribution/คำอธิบาย                            |
| ร้านจริงสร้างรายได้             | ขั้นตอนแพลตฟอร์มหรือลูกค้าไม่ตรงความคิด | ตรวจ program และคุยความต้องการหลังเกมมีผู้เล่น ไม่ลงรายได้สมมติใน forecast |

ไม่อ้างว่าเกมจะเป็นกระแสใหม่เพียงเพราะรวมหลายระบบ สัญญาณที่มีค่าคือผู้เล่นสมัครใจเล่นซ้ำและชวนเพื่อนหลังได้ลอง

## 4. ความเสี่ยงด้านการส่งต่อ AI

อ่านแผนเก่าแล้วสร้างผิดแนว → root README/AGENTS/CLAUDE ชี้แผนปัจจุบัน; แก้ Studio แต่ไม่ export → ไม่ถือว่าส่งงานเสร็จ; ทั้งสอง AI เขียนไฟล์เดียวกัน → ใช้การ claim งานและเจ้าของ session; รายงาน test เก่าเป็นผลใหม่ → ทุก report ระบุ commit/checkpoint และวันที่

โฟลเดอร์ handoff เป็นเอกสารร่วม ไม่ใช่ระบบส่งข้อความเรียลไทม์ ไม่เปิด chat ของอีก AI เองและไม่อ้างว่า Claude ได้รับ/อ่านแล้วหากไม่มีบันทึกจากมัน

## 6. สิ่งที่ยังต้องตัดสินภายหลัง

ชื่อจริงของเกม, กลุ่มผู้เล่น/เครื่องขั้นต่ำ, scope avatar, ขอบเขตแผนที่แน่นอน, ownership บัญชีหรือ group, sync pipeline, test harness, งบงานภาพ และเกณฑ์เปิดให้ทดสอบนอกทีม

ไม่ต้องตอบทุกข้อก่อนอ่านเอกสาร ความไม่แน่นอนที่ขวาง milestone ถัดไปค่อยยกมาคุยพร้อมตัวเลือกและหลักฐาน ข้ออื่นให้คงเป็น Proposed ไม่แต่งคำตอบแทนผู้สร้าง
