# การวิจัยคู่แข่งและเหตุผลของ concept v3

ค้นคว้า: 14 ตุลาคม 2569 (2026-10-14), Asia/Bangkok  
ขอบเขต: หน้าเกม/ผู้พัฒนา/ร้านค้าและตัวอย่างโพสต์สาธารณะ ไม่ใช่การสำรวจเกมทุกเกมหรือข้อมูลผู้เล่นไทยทั้งหมด  
ข้อเสนอที่ตามมา: [GDD v3](../game_design_document.md)

## 1. ในไทยมีเกมใกล้เคียงหรือไม่

มีองค์ประกอบใกล้เคียงหลายส่วน การมีเกมในหน้าร้านไทยยืนยันช่องทางเผยแพร่ที่พบ ไม่ยืนยันจำนวนคนไทยที่เล่นอยู่หรือความนิยมของ concept เรา

| เกมและหลักฐาน | สิ่งที่พบ | บทเรียนที่เลือกใช้ |
|---|---|---|
| [Monster Hunter Now — App Store ไทย](https://apps.apple.com/th/app/monster-hunter-now/id6445906110) | ล่าสัตว์ประหลาดบนโลกจริง พัฒนาอาวุธ และการล่าที่จำกัดเวลา 75 วินาที | ให้การต่อสู้มีเป้าหมายชัดและความก้าวหน้าที่เห็นผล ของเราใช้การเดินทางเสมือนและรอบยาวกว่าเป็นสมมติฐาน |
| [Ingress — App Store ไทย](https://apps.apple.com/th/app/ingress/id576505181) | แผนที่โลกจริง การยึดพอร์ทัลและเชื่อมพื้นที่ร่วมกับฝ่ายเดียวกัน | แผนที่ควรมีผลจากความร่วมมือ แต่ข้อเสนอเราไม่บังคับไปถึงสถานที่จริง |
| [Asura Online — GAMEINDY](https://asura.gameindy.com/) และ [Google Play](https://play.google.com/store/apps/details?id=com.gameindy.asuraonline&hl=th&gl=TH) | มีเกม 2D MMORPG จากผู้พัฒนาไทยที่เน้นพัฒนาตัวละครและต่อสู้ | ความเป็นไทยและเก็บเลเวลมีอยู่แล้ว จึงใช้สองอย่างนี้อย่างเดียวเป็นจุดต่างไม่ได้ |
| [Orna](https://orna.gg/) | GPS RPG ที่มีการต่อสู้แบบ turn-based และระบบชุมชน/อาณาเขต เป็นคู่เทียบต่างประเทศ | Map + RPG + territory ไม่ใช่ชุดแนวคิดใหม่โดยตัวมันเอง ยังไม่ได้ยืนยันช่องทางจำหน่ายไทยในงานรอบนี้ |

ในแหล่งที่ตรวจ ยังไม่พบหลักฐานยืนยันเกมไทยที่ตรงวงจร v3 ทุกขั้น แต่ผลค้นหาไม่เพียงพอให้กล่าวว่า “ประเทศไทยยังไม่มี” หรือ “เป็นเกมแรกของโลก”

ยังไม่มีหลักฐานในงานนี้ว่าคนไทยชอบเกมสงครามมากกว่าเกมอบอุ่นในกลุ่มเป้าหมายเดียวกัน ความต้องการของผู้สร้างและความเป็นไปได้ของวงจรการเล่นเป็นเหตุผลที่เปลี่ยน concept ไม่ใช้ขนาดตลาดเกมไทยแทนผลทดสอบความสนุก

## 2. เกมอื่นที่ใช้ตรวจความใหม่

- [Ravenswatch — ผู้จัดจำหน่าย Nacon](https://www.nacongaming.com/en-US/ravenswatch): แอ็กชัน roguelike มุมมองบน ใช้ฮีโร่จากนิทานและตำนาน บทเรียนคือคาแรกเตอร์ที่จำได้กับการสู้ที่มีบทบาทต่างกัน; นิทานท้องถิ่นกับ co-op เพียงอย่างเดียวไม่ใหม่
- [Magicka — คู่มือผู้จัดจำหน่ายบน Steam](https://cdn.akamai.steamstatic.com/steam/apps/42910/manuals/Magicka%20manual%20body%20--%20English.pdf): มีการผสมธาตุเป็นคาถา บทเรียนคือกติกาที่ทำให้เกิดวิธีใช้หลายแบบ; เราลดจำนวนสิ่งที่ต้องจำและให้เลือกพลังหนึ่งช่อง
- [Meet Your Maker — ประกาศจาก Behaviour](https://media.bhvr.com/meet-your-maker-reveal/): ผู้เล่นสร้างด่านและบุกด่านผู้อื่น จึงไม่ควรเรียก “สร้างด่านให้คนอื่น” ว่าเป็นกลไกใหม่ของเรา
- [Cellyon: Boss Confrontation — หน้าร้านผู้พัฒนา](https://store.steampowered.com/app/802120/Cellyon_Boss_Confrontation/): ระบุเครื่องมือสร้าง boss fight ให้ชุมชน เป็นเหตุผลให้ไม่เลือก boss editor อย่างเดียวเป็นจุดขายใหม่

สิ่งที่ผสมคือหลักการออกแบบ ไม่คัดลอกภาพ ตัวละคร เนื้อเรื่อง เสียง แผนที่เฉพาะเกม หรือโค้ดของเกมเหล่านี้ ความเชื่อมโยงที่เสนอใหม่ในโครงการคือพลังบอสชุดเดียวใช้สู้ ใช้เปลี่ยนพื้นที่ และถูกส่งผ่านเส้นทางให้ทีมถัดไป

## 3. สิ่งที่อ่านได้จาก AI Game Dev Thailand

เข้าดูโพสต์สาธารณะของ [กลุ่ม](https://www.facebook.com/groups/aigamedevthailand) ได้บางส่วน ก่อนพบหน้าบังคับเข้าสู่ระบบในการขยายโพสต์เพิ่มเติม จึงเป็นตัวอย่างที่เลือก ไม่ใช่การสรุปความเห็นทั้งกลุ่ม ไม่ได้โพสต์ ติดต่อผู้เขียน หรือทดสอบเกมที่ลิงก์ไว้

### FORGE & SIEGE

[โพสต์ของ Peet Peet](https://www.facebook.com/groups/aigamedevthailand/posts/1462327202470677/) อธิบายเกมบนเว็บแบบชิงธง มีนักดาบ นักธนู และช่างสร้าง พร้อมบอทเติมทีม ผู้สร้างระบุรองรับทีมได้ถึง 30 ต่อ 30 ซึ่งยังไม่ได้ตรวจ load test หรือจำนวนผู้เล่นจริง

สิ่งที่นำมาใช้เป็นแรงบันดาลใจ: บทบาทช่วยทีมควรสร้างผลในสนามทันที เช่น เปิดทางหรือสร้างกำบัง และการเริ่มเล่นไม่ควรติดจำนวนคนออนไลน์ขั้นต่ำ เราไม่ใช้คำกล่าวเรื่องขนาดห้องเป็นหลักฐานว่า stack ใดรองรับได้แน่นอน

### Pipeline Blender / AI

[โพสต์ของ Bom Kuntiwong](https://www.facebook.com/groups/aigamedevthailand/posts/1462371529132911/) เล่าการเชื่อม AI กับ Blender MCP เพื่อทำ rig/animation จาก GLB เป็นประสบการณ์ผู้เขียน ไม่ใช่ benchmark ที่ตรวจซ้ำแล้ว

[โครงการ MCP for Blender](https://github.com/ahujasid/mcp-for-blender) เป็นโครงการชุมชนสำหรับเชื่อมเครื่องมือกับ Blender และระบุว่าไม่ได้เป็นโครงการของ Blender Foundation การมีเครื่องมือไม่ได้ยืนยันว่าทำ animation คุณภาพพร้อมใช้งานได้อัตโนมัติทุก asset

ข้อเสนอ: ทดลองกับ asset หนึ่งตัวและตรวจ skeleton, loop, export และการเล่นใน engine ก่อนเลือก pipeline ไม่เลือกโมเดลจากคำจัดอันดับในโพสต์ และต้นแบบ 2D รอบแรกยังไม่ต้องมี pipeline 3D

### วิธีใช้กลุ่มต่อ

ใช้เป็นแหล่งดูงานจริงและหาปัญหาการผลิตที่คนอื่นเจอ เลือกทดลองทีละเทคนิคเมื่อแก้ปัญหาเฉพาะได้ จำนวนสมาชิก ปฏิกิริยา และคำชมโพสต์ไม่ใช่หลักฐานว่าผู้เล่นทั่วไปจะกลับมาเล่นเกมเรา

## 4. การคัด concept

| ทางเลือก | จุดดึงดูด | เหตุผลตัดสิน |
|---|---|---|
| MMORPG บนแผนที่ไทย | โตเป็นตัวเทพและเล่นกับเพื่อน | กว้างเกินไปสำหรับจุดขาย และมีภาระ content/online สูง |
| สร้างบอสให้จังหวัดอื่นบุก | เล่าได้ง่ายและมีเนื้อหาจากผู้เล่น | พบเกมที่มี boss/dungeon editor อยู่แล้ว ต้องมีเหตุผลเพิ่มจึงจะต่าง |
| ล่าพลังแล้วเปลี่ยนพื้นที่ส่งต่อ | การต่อสู้ การเติบโต และ community ใช้พลังชุดเดียวเชื่อมกัน | เลือกพิสูจน์ เพราะมีกลไกให้ map เปลี่ยนการเล่นถัดไปโดยตรง |

นี่เป็นการประเมินเชิงออกแบบ ไม่ใช่คะแนนจากผู้เล่น ความใหม่ที่รับรู้และความสนุกยังต้องผ่านต้นแบบตามเกณฑ์ใน GDD

## 5. ความเป็นไปได้ทางเทคนิคที่ตรวจแล้ว

[Phaser](https://docs.phaser.io/phaser/getting-started/what-is-phaser) รองรับเกม 2D บนเว็บด้วย JavaScript/TypeScript ส่วน [Colyseus](https://docs.colyseus.io/) มีห้องเกมและ state synchronization ฝั่งเซิร์ฟเวอร์ที่ถือผลเกมเป็นหลัก จึงเป็นตัวเลือกสำหรับต้นแบบแอ็กชันร่วมมือ

เอกสารเครื่องมือไม่ได้ยืนยัน performance ของเกมนี้ ยังต้องวัดมือถือ เครือข่าย การชน และการเชื่อมต่อใหม่ เลือกเวอร์ชันที่ทำงานร่วมกันหลังทดลอง ไม่ยึดคำว่า latest เป็นข้อกำหนด
