# ผลจำลองสมดุล

สร้างโดย `tools/balance-sim` (ผู้เล่นจำลอง 3 แบบ เล่น 30 วัน ใช้ `game-core` ตัวเดียวกับเกมจริง)

| ไฟล์ | คืออะไร |
|---|---|
| `progression.html` | กราฟเลเวล ด่านที่ผ่าน สกิล + ตารางเทียบเป้าหมาย + เทียบสายธาตุ (เปิดในเบราว์เซอร์) |
| `progression.csv` | ตัวเลขรายวันของแต่ละแบบผู้เล่น |
| `summary.json` | จุดสำคัญ (เวล 10/30/60, อัปร่าง, เคลียร์ย่านแรก) |
| `targets.txt` | ผ่าน/ไม่ผ่านเทียบเป้าหมายใน `docs/development_plan.md` M1.4 |

รันใหม่:

```
pnpm --filter balance-sim sim
```

ตัวเลขทุกตัวมาจาก `packages/game-core/config/balance.json` และ `monsters.json` แก้แล้วรันใหม่ได้เลย

## ข้อจำกัด (ต้องรู้ก่อนเชื่อผล)

- เป็นผู้เล่นจำลองที่ใช้นโยบายง่าย ๆ ไม่ใช่คนจริง ผลบอกว่า "ระบบไม่พัง/ไม่เร็วเกินไป" ไม่ได้บอกว่า "สนุก"
- ใช้กฎย่านแบบ "ไม่มีกฎ" ตลอด ยังไม่จำลองการแบกเพื่อน
- เกณฑ์ผ่านเป็นสมมติฐานของทีม ไม่ใช่มาตรฐานตลาด
