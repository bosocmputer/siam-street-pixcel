# นักดาบบุคคลที่หนึ่ง: ต้นแบบการต่อสู้

ผู้สร้างขอให้ใช้เมืองเป็นฉาก MMORPG เอาชื่อสถานที่/หมุดออก และเริ่มต่อสู้กับสไลม์
บริเวณท่าแพด้วยนักดาบ เห็นแขนและดาบ งานนี้ทำวงจรเล่นในเครื่องก่อน ระบบออนไลน์ยังไม่มี

## พฤติกรรม

- เริ่มที่ลานด้านนอกประตูตะวันออก มีสไลม์ 3 ตัว ใช้พิกัดโลกเดียวกับ OSM
- WASD เดิน, Shift วิ่ง, ลากเมาส์มอง, คลิกฉากล็อกเมาส์
- F/คลิกซ้ายฟัน: ระยะ 3.05 เมตร คูลดาวน์ 0.6 วินาที ใช้ความอึด 12
- ความเสียหายเริ่มต้น 26, สไลม์ HP 70, ผู้เล่น HP 100
- Q/คลิกขวาค้างตั้งรับด้านหน้า: ลดดาเมจ 12 เหลือ 3 และใช้ความอึด 14
- สไลม์เตือนสีเหลือง 0.65 วินาที ถอยพ้นระยะ 1.85 เมตรเพื่อหลบ
- ฟันโดนทำให้สไลม์ชะงัก 0.4 วินาที ตรวจแนวกำแพงทั้งการฟันและสไลม์โจมตี
- สไลม์ตายได้ 20 XP เกิดใหม่ใน 8 วินาที สังหาร 3 ตัวผ่านภารกิจฝึก
- XP เต็ม (เลเวล × 60) เพิ่มเลเวล ดาเมจ +4 เลือดสูงสุด +10 และฟื้นเลือด 30
- P พักเกม, M แผนที่, V มุมสูง, Esc ปล่อยเมาส์และพัก
- E / ปุ่มจันทร์ผ่าวิญญาณ: ชาร์จ 0.9 วินาที ปล่อยคลื่นจันทร์เสี้ยวแนวราบตามทิศมอง
  ตอนปล่อย ความเร็ว 18 เมตร/วินาที ระยะ 30 เมตร ดาเมจ 3 เท่าของดาบ (เริ่มต้น 78)
- คลื่นทะลุศัตรูหลายตัวได้ ตัวละหนึ่งครั้ง แต่หยุดเมื่อชนสิ่งกีดขวาง และไม่โจมตีผ่านกำแพงข้างทาง
- ใช้พลังวิญญาณ 35/100 ฟื้น 8 ต่อวินาที คูลดาวน์ 5 วินาทีเริ่มเมื่อกดใช้
- ระหว่างชาร์จเดินช้าลง ไม่ฟันธรรมดาหรือตั้งรับ เล็งซ้าย/ขวาได้จนกว่าจะปล่อยคลื่น
- แสงดาบ อนุภาคไหลเข้าหาคมดาบ วงพลัง ท่าฟัน คลื่นเรืองแสง และรอยพลังตามพื้น
  ใช้ geometry/texture ที่สร้างในโค้ด ไม่ต้องโหลด asset เพิ่ม
- มือถือมีจอยเดิน ปุ่มฟัน และปุ่มตั้งรับแบบกดเปิด/ปิด
- เมื่อออกจากหน้าจอ เปิด dialog หรือเปิดแผนที่/มุมสูง การต่อสู้หยุด
- ตายแล้วเริ่มใหม่ได้ รีเซ็ต HP, XP, สไลม์ และตำแหน่ง

## โครงสร้างและขอบเขต

`combat.ts` แยก simulation จาก Three.js ใช้เวลา simulation และข้อมูลพิกัดล้วน
จึงทดสอบจังหวะโจมตีได้โดยไม่ต้องเรนเดอร์ `combat-view.ts` รับ event เพื่อแสดงโมเดล
แอนิเมชัน ตัวเลขดาเมจ เศษสไลม์ และ health label
`spirit-wave-view.ts` แยกเอฟเฟกต์ชาร์จและคลื่นออกจากโมเดลดาบ/สไลม์
ค่าปรับสมดุลรวมใน `SPIRIT_WAVE` ที่ `combat.ts` ไม่มีตัวแปรทดสอบที่ใช้แก้เกมจาก browser global

ไม่มีบัญชี ผู้เล่นอื่น บันทึกความคืบหน้า inventory หรือเซิร์ฟเวอร์ เมื่อทำออนไลน์
ต้องใช้ server-authoritative simulation และตรวจ input แทนการเชื่อสถานะ client
สไลม์ใช้เดินตรงพร้อม collision และ leash ยังไม่มี navigation mesh/pathfinding รอบตึก
โมเดลตัวละคร/ดาบ/สไลม์สร้างจาก geometry ในโค้ด ไม่มี asset ภายนอกเพิ่มเติม

## ตรวจรับ

1. เปิด `pnpm dev:world` กดเริ่มต่อสู้ เห็นแขน ดาบ และสไลม์ที่ลานประตู
2. กด W ประมาณ 0.9 วินาที จากนั้น F ฟันในระยะ เห็นแถบเลือดสไลม์ลด
3. ฟันครบสามครั้งเว้นคูลดาวน์ สไลม์ตาย จำนวนสังหารเพิ่ม และ XP +20
4. รอให้สไลม์โจมตี Q ค้างได้รับดาเมจ 3 ถ้าหันถูกด้าน ไม่ตั้งรับได้รับ 12
5. ปล่อยให้ถูกโจมตีจนตาย กดเริ่มใหม่ ต้องกลับ HP 100, XP 0 และสังหาร 0
6. กด P เปิดแผนที่ หรือเปิดมุมสูง สถานะต่อสู้ต้องไม่เดินต่อ
7. ตรวจที่ 390×844 ไม่มีแนวนอนล้น ปุ่มฟันและตั้งรับใช้งานได้
8. รัน test, typecheck, eslint และ build ของ `@siam/chiangmai-world`

ผลตรวจใน in-app browser: ฟันสไลม์ HP 70 → 44 → ตาย ได้ XP 20;
ตั้งรับ HP 100 → 97; ถูกโจมตีจน HP 0 และเริ่มใหม่กลับ 100 ได้
ปุ่มมือถือเปิดตั้งรับได้ และ viewport 390×844 ไม่มี horizontal overflow
ข้อมูล readonly `data-hp`, `data-kills`, `data-slimes`, `data-paused` ช่วยตรวจสถานะ
ไม่มีเมธอดแก้เกมผ่าน browser global

เทสต์ฉากทั้งหมด 22 ข้อ รวมต่อสู้ 10 ข้อ ผ่าน; ตรวจ mutation ของเงื่อนไขความอึด
ในการตั้งรับแล้ว เทสต์จับข้อผิดพลาดได้ 2 ข้อ จากนั้นคืนเงื่อนไขที่ถูกต้อง
Typecheck, ESLint, Prettier และ production build ผ่าน โดย build ยังเตือน bundle ของ
3D engine เกิน 500 kB ตามข้อจำกัดที่บันทึกไว้ในงานฉากก่อนหน้า

## ตรวจรับสกิลจันทร์ผ่าวิญญาณ

1. เริ่มเกมแล้วยืนที่เดิม กด E เห็นแขนยกดาบ แสงและอนุภาครวมพลัง พร้อมแถบชาร์จ
2. เมื่อครบ 0.9 วินาที เห็นคลื่นรูปจันทร์เสี้ยวพุ่งออกไป สไลม์ด้านหน้าตายและได้ XP 20
   โดยผู้เล่นยังไม่ได้เดินเข้าระยะฟันธรรมดา
3. กดซ้ำใน 5 วินาทีไม่ได้ พลังวิญญาณลดและฟื้นกลับเอง
4. หันกล้องระหว่างชาร์จ คลื่นใช้ทิศตอนปล่อย หลังปล่อยแล้วคลื่นไม่เลี้ยวตามกล้อง
5. คลื่นชนกำแพงต้องหายไป ไม่ทำความเสียหายผ่านกำแพง
6. มือถือ 390×844 กดปุ่มสกิล เห็นชาร์จและปล่อยคลื่นได้ ไม่มี horizontal overflow
7. ตาย/เริ่มใหม่ต้องไม่มีคลื่นหรือเอฟเฟกต์ชาร์จเก่าค้าง และคืนพลังวิญญาณ 100

ตรวจจริงบนคอมและ viewport มือถือ: ยืนที่พิกัดเริ่มต้น (เดิน 0 เมตร) กดสกิล
สไลม์ตัวแรก HP 70 → 0, XP 20 และยังเห็นคลื่นพุ่งต่อไปได้
เทสต์ปัจจุบันผ่าน 30 ข้อ รวมสกิลคลื่นพลัง 8 ข้อ; Typecheck, build, ESLint และ Prettier ผ่าน
Console ของการทดลองในเบราว์เซอร์ไม่มี error/warning; build ยังเตือนขนาด bundle ของ 3D engine
