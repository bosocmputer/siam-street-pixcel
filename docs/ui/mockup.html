M2.5 · รอบที่ 1

แบบหน้าจอ สไลม์คุมย่าน รออนุมัติ

นี่คือภาพจำลองหน้าจอ ก่อนเขียนโค้ดจริง ใช้ขนาดมือถือ 390×844 ภาพสไลม์ มอน และฉากเป็นของวาดชั่วคราว จะถูกแทนด้วย pixel art จาก PixelLab เมื่อต่อได้ ตัวเลขในภาพเป็นตัวอย่าง

อยากให้คุณตัดสินแค่ 5 เรื่อง (ตอบสั้น ๆ ก็พอ ผมแก้ได้ถูกที่สุดตอนนี้)
  1. บรรยากาศ ตลาดกลางคืนเชียงใหม่ (ม่วงเข้ม + แสงโคมสีส้ม) ใช่ไหม หรืออยากได้อารมณ์อื่น
  2. หน้าฟาร์มที่เห็นสไลม์ใหญ่ครึ่งจอ ดูเป็นเกมขึ้นไหม
  3. ปุ่มส้มใหญ่ "เก็บของออโต้" ตัวเดียวต่อหน้า ชัดพอไหม
  4. หน้าแผนที่แบบภาพแทนรายการ อยากได้ทิศทางนี้ไหม (ของจริงมาจาก OSM ใน M3)
  5. มีหน้าไหนที่รู้สึกว่า "ยังเหมือนแอปทั่วไป" บอกได้เลย
ก่อน → หลัง

หน้าฟาร์ม: ปัญหาของ M2 และสิ่งที่แก้

ที่ผมเห็นว่าผิดใน M2

  • ฉากต่อสู้เป็นแถบเล็ก สไลม์ซึ่งเป็นพระเอกตัวนิดเดียว ไม่มีบรรยากาศ
  • ปุ่มรับของ "รอสักครู่ (29 วิ)" หน้าตาเหมือนปุ่มที่ใช้ไม่ได้ ทั้งที่เป็นปุ่มหลักของเกม
  • ข้อมูลเรียงเป็นแถบข้อความ ไม่มีลำดับสายตา อ่านแล้วต้องแปลเอง
  • กล่องคำแนะนำซ้อนหลายอัน ผู้เล่นไม่รู้ว่าควรทำอะไรก่อน
  • ทุกแผงหน้าตาเหมือนกัน ไม่มีอะไรบอกว่าอันไหนสำคัญ

ที่แก้ในแบบใหม่

  • ฉากต่อสู้ใหญ่ครึ่งจอ มองจากมุมสูงแบบเดียวกับที่ PixelLab ทำ (low top-down)
  • "ถุงของออโต้" แสดงเป็นรูปที่ค่อย ๆ เต็ม แทนแถบข้อความ ปุ่มส้มเป็นปุ่มเดียวที่ใหญ่ที่สุด
  • คำแนะนำเหลือ ริบบิ้นเดียว เรียงลำดับความสำคัญให้ และจุดแดงบนแท็บ
  • ขอบแบบพิกเซล (มุมแหว่ง) ทุกอย่าง ไม่ใช่กล่องมุมมน
ลองกดได้

ต้นแบบกดดูได้

กดแท็บด้านล่างสลับหน้า และกดปุ่ม "เก็บของออโต้" บนหน้าฟาร์มเพื่อดูหน้าสรุป ลองกดช่องบนหน้าสไลม์/สกิลได้บางจุด

เป็นภาพจำลอง ไม่ใช่เกมจริง ตัวเลขทุกตัวเป็นตัวอย่าง ยังไม่ได้ลองบนมือถือจริง

หลักการ 6 ข้อที่ทุกหน้าต้องผ่าน

  • พระเอกหนึ่งอย่างต่อหน้า ฟาร์ม = สไลม์ในฉาก สไลม์ = ตัวสไลม์พร้อมของที่ใส่
  • ปุ่มหลักหนึ่งปุ่ม สีส้มเท่านั้น ปุ่มอื่นเป็นรอง
  • ข้อความสั้น ไม่เกิน 6 บรรทัดต่อหน้าจอ (ไม่นับรายการของ)
  • นิ้วโป้งถึง ปุ่มที่ใช้บ่อยอยู่ครึ่งล่าง ไม่ต้องเอื้อมขึ้นบน
  • ของใหม่ต้อง "ดู" ได้ ไม่ใช่อ่าน ได้ของ = เห็นไอคอนเด้ง ไม่ใช่ตัวเลขในตาราง
  • กดแล้วต้องมีผล ทุกปุ่มมีการตอบสนอง (เด้ง/แสง/ตัวเลขลอย)
เส้นทางผู้เล่น

นาทีแรก → ครั้งที่สอง → วันที่ 3

นาทีแรก · ~60 วินาที

เห็นแล้วอยากเล่นต่อ

  1. แตะไข่ → สไลม์ฟัก (แสงวาบ)
  2. สร้างสไลม์ของเรา ชื่อ สี หน้าตา ตัวอย่างเปลี่ยนทันที
  3. มอนตัวแรกมา กด "กลืนเลย!" ปุ่มเดียว
  4. ส่วนงอกโผล่ที่ตัวสไลม์ (ช่วงที่ต้อง "ว้าว")
  5. เข้าฟาร์ม เห็นสไลม์สู้เอง และถุงของออโต้เริ่มเต็ม
กลับมาครั้งที่สอง · ~2 นาที · หายไป 2–3 ชม.

มีของรอเสมอ

  1. เปิดมา เห็นถุงเต็ม ปุ่มส้มกระพริบ "เก็บของออโต้"
  2. หน้าสรุปแบบเปิดของ: ไอเทมเด้งทีละชิ้น มอนทองถ้าเจอ
  3. ริบบิ้นบอกขั้นต่อไป เช่น "มีแก่น 3 ชิ้น → กลืน"
  4. ไปหน้าสกิล กด "กลืนเลย!" แล้วใส่ของที่ได้
  5. กลับฟาร์ม เห็นตัวสไลม์เปลี่ยนไป แล้วปิดแอป
วันที่ 3 · ราวเวล 28 (ตามผลจำลอง)

มีเรื่องให้วางแผน

  1. เก็บของ 2–3 ครั้งต่อวัน แต่ละครั้งไม่เกิน 2 นาที
  2. เลือกย่านเรา (ริบบิ้นเตือนที่เวล 3) และดูแรงก์ (หลัง M4–M5)
  3. เปลี่ยนชุดสกิลให้ได้คอมโบ ลองตื่นพลังสกิลที่เต็ม
  4. ดูบอสย่านประจำสัปดาห์ (หลัง M5)
  5. ตั้งเป้าด่านถัดไปที่แผนที่ แล้วปิดแอป

ข้อจำกัดตามจริง

ที่ยังไม่ใช่ของจริง

  • ภาพสไลม์ มอน ฉาก และไอคอนทั้งหมดวาดชั่วคราวด้วยโค้ดเพื่อทดสอบ layout ยังไม่ใช่ภาพจาก PixelLab
  • แผนที่เป็นภาพเลียนแบบรูปทรงคร่าว ๆ ตำแหน่งและขอบเขตย่านจริงมาจาก OSM ใน M3
  • ยังไม่ได้ทดสอบบนมือถือจริงและยังไม่ได้ทำเสียง
  • เกมจริงจะใช้ฉากมุม low top-down ตามมาตรฐานสไตล์ภาพที่วางไว้ ตัวสไลม์ในฉากอาจต่างจากภาพนี้
  • ตัวอย่างพูดถึงมอนและฉากที่เป็นของย่านในเวียง ไม่ใช้วัดหรือศาสนสถานเป็นสนามต่อสู้ตามกติกาโครงการ
