# 1. EXECUTIVE SUMMARY & CONCEPT OVERVIEW

### 1.1 วิสัยทัศน์ของโครงการ (Vision)
**Siam Street Pixel** คือเกมแนว **Web-Based Idle Tycoon & Urban Management** ที่เปลี่ยนพิกัดแผนที่ประเทศไทยจริง (GPS & 3D Building Data) ให้กลายเป็นสนามเล่นเกมพิกเซลสุดน่ารักและกวนๆ ผู้เล่นไม่จำเป็นต้องออกไปเดินตากแดด ไม่ต้องเปิดหน้าจอค้างไว้ แต่สามารถสร้างอาณาจักรขนส่ง คาเฟ่ และยึดแลนด์มาร์กสำคัญทั่วประเทศไทยได้ผ่านการดำเนินชีวิตประจำวัน

### 1.2 จุดเด่นที่สร้างความแตกต่าง (USPs)
1. **3D Real-World + 2D Pixel Art (HD-2D Visuals):** สแกนโครงสร้างตึก ถนน และสถานที่จริงทั่วประเทศไทยจาก OpenStreetMap (OSM) แปลงเป็นฉาก 3D Voxel แล้วซ้อนทับด้วยตัวละคร/ยูนิต 2D Pixel Art
2. **Web-First Accessibility:** เล่นผ่าน Web Browser ได้ทันทีโดยไม่ต้องดาวน์โหลดแอปพลิเคชัน (No App Store Barrier) แชร์ลิงก์เข้าเล่นได้ทันที
3. **Passive Life-Sync & Offline Idle:** ไม่กินเวลาชีวิต ไม่กินแบตเตอรี่ ปิดเบราว์เซอร์ไปเรียน/ทำงาน ระบบยังฟาร์มเงินและดำเนินธุรกิจให้อัตโนมัติ
4. **Local Thai Pop Culture & Real-World Value:** นำเอกลักษณ์ วิถีชีวิต ความกวน และ Pop Culture ไทยมาทำเป็นมอนสเตอร์/ยูนิต พร้อมระบบแลกคูปองส่วนลดร้านค้าจริง

# 2. STORY, WORLDBUILDING & LORE

### 2.1 ฉากหลังของเรื่อง (Lore)
ในอดีต สถานที่สำคัญ ถนน และสิ่งก่อสร้างทั่วประเทศไทยถูกเชื่อมโยงไว้ด้วย **"เส้นพลังงานมิติซ้อน" (Leyline Network)** แต่เมื่อเทคโนโลยี 5G, คลื่นวิทยุ และสมาร์ตโฟนครอบคลุมทั่วประเทศ ได้เกิดปรากฏการณ์ **"Digital Interference"** ทำให้มิติขนานเปิดออก

ความทรงจำ อารมณ์ และวิถีชีวิตของผู้คนในแต่ละย่าน (เช่น ความรีบร้อนของแยกอโศก, ความชิลของคาเฟ่นิมมาน, ความขลังของเมืองเก่าลำปาง) ได้ควบแน่นกลายเป็นสิ่งมีชีวิตและวัตถุมีชีวิตสไตล์พิกเซล เรียกว่า **"Street Pixels"** 

### 2.2 บทบาทของผู้เล่น (Player Role)
ผู้เล่นจะได้รับบทเป็น **"City Manager / เจ้าพ่อธุรกิจมิติซ้อน"** ที่ได้รับแว่นตามิติมองเห็นเมืองไทยในมุมมอง 3D Voxel มีหน้าที่สร้างเครือข่ายโลจิสติกส์ เปิดร้านค้าพิกเซล แข่งขันยึดแลนด์มาร์ก และรวบรวมยูนิตพิกเซลประจำย่านต่างๆ เพื่อก้าวเป็นมหาเศรษฐีอันดับ 1 ของประเทศ

# 3. FULL CORE GAME MECHANICS (ระบบเกมทั้งหมด)

```
                       [ 3D FREEMAP & GPS Data ]
                                   │
         ┌─────────────────────────┼─────────────────────────┐
         ▼                         ▼                         ▼
[ 1. Base Building ]      [ 2. Idle Logistics ]    [ 3. Landmark Turf War ]
 - ปักหมุด Pixel HQ         - วางเส้นทางส่งของ        - ยึดแยก/ห้าง/สนามบิน
 - ตกแต่งตึก 3D Voxel       - พนักงานสุ่ม (Gacha)     - ป้ายไฟนีออนชื่อแก๊ง
 - แผงลอยข้างตึก            - Real-time Sync          - เก็บภาษีประจำย่าน
```

### 3.1 ระบบศูนย์บัญชาการ & ปักหมุดตึก (Pixel HQ & Building)
* **Starter HQ:** ดึงพิกัด GPS ปัจจุบันของผู้เล่น แปลงตึกจริงรอบตัวในรัศมี 300 เมตรเป็น 3D Voxel ผู้เล่นเลือก 1 ตึกเพื่อเป็นศูนย์บัญชาการ
* **Building Upgrade:** นำเงิน Gold ที่ได้จากการดำเนินธุรกิจมาอัปเกรดตึก 3D ให้สูงขึ้น ติดไฟนีออน เพิ่มความจุคลัง และเพิ่มโบนัสการทำเงิน
* **Micro-Vendor Placement (แผงลอยข้างตึก):** ผู้เล่นใหม่สามารถนำ "แผงลอยพิกเซล" (เช่น รถหมูปิ้ง, ชาเย็น) ไปตั้งข้างตึก 3D ของผู้เล่นคนอื่นเพื่อเกาะกระแสทำเงิน

### 3.2 ระบบสุ่มพนักงาน & ยูนิตขนส่ง (Staff & Logistics)
* **Gacha System:** สุ่มหาตัวละครพิกเซลสไตล์ไทยสุดกวน แบ่งเป็น 5 ระดับความหายาก: `Common` | `Uncommon` | `Rare` | `Epic` | `Legendary`
* **ตัวอย่างยูนิต:**
  * *พี่วินสายสปีด:* วิ่งส่งของไวในระยะสั้น (0–1 กม.) เหมาะกับย่านอโศก/สยาม
  * *รถแดงเชียงใหม่:* ขนส่งสินค้าได้ครั้งละเยอะๆ ในโซนภาคเหนือ
  * *รถม้ามลำปาง:* ยูนิตคลาสสิก เพิ่มบัฟเงินกำไรจากสินค้าโบราณ +30%
  * *เทพไรเดอร์มิติซ้อน (Legendary):* วิ่งข้ามจังหวัดได้ทันทีโดยไม่ติดขัด

### 3.3 ระบบเส้นทางส่งของ & Idle Progress
* **Route Setup:** ผู้เล่นสั่งลากเส้นทางจาก Pixel HQ ไปยังจุดแลนด์มาร์กใกล้เคียง (ป้ายรถเมล์, คาเฟ่, ห้าง) เพื่อส่งสินค้าประจำย่าน
* **Offline Progress:** ปิดเบราว์เซอร์ไปใช้ชีวิต ระบบจะคำนวณเงินสะสมให้อัตโนมัติสูงสุด 12 ชั่วโมง (อัปเกรดเป็น 24 ชม. ได้)

### 3.4 ระบบซิงก์โลกจริง (Real-World Dynamic Sync)
* **Weather Sync:** เชื่อมต่อ Weather API
  * *ฝนตกจริง:* ยูนิตสายเดลิเวอรี่/ชาชานม ทำกำไร X2
  * *แดดแรง:* สินค้าประเภทเครื่องดื่มเย็น/น้ำปั่น ขายดีขึ้น 80%
* **Traffic Sync:** จราจรติดขัดจริง ยูนิตประเภท "พี่วิน" หรือ "ซอยลัด" จะได้โบนัสเงินเพิ่ม
* **Calendar Sync:** วันหวยออก (1 และ 16) ศาลเจ้า 3D ในเกมจะมี NPC พิกเซลต่อคิวแน่น เกิดเควสส่งแผงล็อตเตอรี่พิกเซล

### 3.5 ระบบสติ๊กเกอร์ & โปสต์การ์ด (Pixel Postcards)
* สะสม **"Pixel Travel Postcards"** เมื่อส่งของหรือเปิดสาขาสำเร็จในสถานที่สำคัญทั่วไทย
* สะสมครบเซ็ตประจำจังหวัด ได้รับ Buff สเตตัสถาวร + สามารถกด Export รูปภาพลง IG Stories / TikTok ได้ทันที

### 3.6 ระบบแก๊ง & สงครามยึดแลนด์มาร์ก (District Crew & Anti-Monopoly Turf War)
* **District Crew:** รวมกลุ่มกับเพื่อน 5–20 คน สร้างแก๊งประจำย่าน
* **Weekly Auction:** ประมูลยึดแลนด์มาร์กใหญ่ (เช่น แยกอโศก, ประตูท่าแพ, สนามบิน) ทุกๆ 7 วัน
* **Rewards:** ผู้ชนะจะได้ขึ้นป้ายไฟนีออนชื่อแก๊งสว่างไสวบนตึก 3D + ได้รับภาษีการค้า 2% จากผู้เล่นทุกคนที่ส่งของผ่านย่านนั้น
* **Anti-Monopoly Rule:** แก๊งที่ยึดพื้นที่เดิมซ้ำกันเกิน 2 สัปดาห์ จะต้องเสียค่าบำรุงรักษาแพงขึ้นเรื่อยๆ เพื่อเปิดโอกาสให้แก๊งใหม่ๆ สู้ราคาไหว

### 3.7 ระบบจุติธุรกิจ & มิติมืด (Prestige & Parallel Realm)
* เมื่อธุรกิจขยายจนล้นประเทศ ผู้เล่นสามารถกด **"Rebirth Franchise"**
* รีเซ็ตเงิน Gold แต่จะได้ **"Void Gems"** นำไปแลก **"สกินเมือง 3D พิเศษ"** (เช่น สกินเมืองไทยไซเบอร์พังก์, สกินอโยธยาโบราณ 3D) พร้อมบัฟทำเงินถาวร +100%

# 4. USER EXPERIENCE & PLAYER ONBOARDING

```
[ Step 1: Scan / Click Link ] ──> [ Step 2: Auto GPS & 3D Render ] ──> [ Step 3: Claim Free HQ ] ──> [ Step 4: First Route ]
   (สแกน QR / เข้าเว็บ)              (ดึงพิกัดตึก 3D รอบตัว)               (เลือกตึกแรกของตัวเอง)        (ส่งพี่วินไปส่งกาแฟ)
```

1. **Accessing:** ผู้เล่นสแกน QR Code หรือกดลิงก์ `siamstreetpixel.com` ผ่านสมาร์ตโฟน
2. **GPS Authorization:** กดอนุญาตตำแหน่ง GPS $\rightarrow$ หน้าจอเรนเดอร์เมือง 3D Voxel รอบตัวผู้เล่นภายใน 3 วินาที
3. **Tutorial (1 นาที):**
   * ระบบแจกฟรี **"ตึก HQ ระดับ 1"** + พนักงานฟรี **"พี่วินสายสปีด"**
   * ทดลองลากเส้นทางส่ง "กาแฟพิกเซล" ไปป้ายรถเมล์หน้าบ้าน
   * ได้รับเงิน Gold ก้อนแรก + สติ๊กเกอร์โปสต์การ์ดใบแรก
4. **Retention Hook:** ระบบแจ้งเตือน *"ปิดเว็บไปพักผ่อนได้เลย! พนักงานของคุณจะส่งของต่อให้ อีก 4 ชั่วโมงกลับมาเก็บเงินนะ"*

# 6. MONETIZATION & REAL-WORLD ECONOMY

### 6.1 โมเดลการสร้างรายได้ (Monetization Models)
1. **Gacha & Battle Pass (B2C):**
   * *Gacha Tickets:* ซื้อเพชรเพื่อสุ่มพนักงานระดับ Epic/Legendary หรือสกินยานพาหนะพิกเซล
   * *Street Pass (Monthly):* บัตรผ่านรายเดือน เพิ่มคลังเก็บเงิน Offline เป็น 24 ชม. + ได้สกินตึกพิเศษ
2. **Real-World Merchant Sponsorships (B2B):**
   * ร้านค้าจริง (เช่น ร้านกาแฟ, ร้านอาหาร) จ่ายค่าสปอนเซอร์ เพื่อให้ตึกร้านจริงของตนในแผนที่ 3D กลายเป็น **"Special Quest Hub"**

# 7. TECHNICAL ARCHITECTURE & DEVELOPMENT STACK

เพื่อให้เกมเล่นบน Web Browser บนมือถือได้อย่างลื่นไหล ไม่กระตุก ทีมพัฒนาควรใช้ Stack เทคโนโลยีดังนี้:

```
[ Frontend: Web Browser ]
 ┣━ 3D Engine: Mapbox GL JS / MapLibre GL (ดึงข้อมูลตึก 3D OSM) + Three.js
 ┣━ 2D Engine: PixiJS (เรนเดอร์ Sprite Pixel Art ลื่นไหล 60 FPS)
 ┗━ Framework: React.js + Tailwind CSS + PWA Support

[ Backend & Infrastructure ]
 ┣━ Runtime: Node.js (TypeScript) / Go
 ┣━ Database: PostgreSQL + PostGIS Extension (จัดการข้อมูล GPS & พิกัด)
 ┣━ Cache & Real-time: Redis + Socket.io (ระบบแก๊ง & อีเวนต์ Real-time)
 ┗━ Cloud Hosting: AWS / Google Cloud Platform (GCP)
```

### 7.1 การจัดการ Performance บน Mobile Browser
* **LOD (Level of Detail):** เรนเดอร์ตึก 3D เฉพาะในรัศมี 300 เมตรรอบตัวผู้เล่น ตึกที่อยู่ไกลออกไปจะถูกลดรายละเอียดโมเดลลง
* **Sprite Sheet Optimization:** รวมภาพ Pixel Art ทั้งหมดเข้าเป็น Texture Atlas เพื่อลดการเรียก Draw Calls ของ GPU

# 8. RISK ANALYSIS & MITIGATION STRATEGIES

| ความเสี่ยง (Risk) | ผลกระทบ | วิธีป้องกันและแก้ไข (Mitigation Strategy) |
| :--- | :--- | :--- |
| **1. GPS Spoofing / โกงพิกัด** | ปานกลาง | เนื่องจากไม่ใช่เกมเดินจับมอนแบบแข่งขันตำแหน่ง แต่เน้นการบริหารจัดการไทคูน จึงใช้การควบคุมด้วยสปีดการขนส่ง และจำกัดการวาร์ปข้ามจังหวัดด้วยคูลดาวน์ |
| **2. ข้อมูลตึก 3D ในต่างจังหวัดไม่สมบูรณ์** | ปานกลาง | ใช้ระบบ **Procedural Voxel Generation** หากโซนไหนไม่มีข้อมูลตึกใน OSM ระบบจะสร้างอาคารบ้านเรือนพิกเซลทรงไทย/คาเฟ่สุ่มขึ้นมาแทนอัตโนมัติ |
| **3. ผู้เล่นสายฟรีสู้สายเปย์ไม่ได้** | สูง | ใช้ระบบ **Anti-Monopoly** หมุนเวียนสัมปทานทุก 7 วัน และจำกัดให้แก๊งใหญ่ต้องจ่ายค่าธรรมเนียมสูงขึ้นหากครองพื้นที่เดิมนานเกินไป |
| **4. Performance เบราว์เซอร์กระตุก** | สูง | ใช้ PixiJS ซ้อนทับ Three.js เพื่อแยก Layer 2D/3D และทำระบบจำกัด FPS (30/60 FPS) ให้ผู้เล่นปรับตามสเปกมือถือ |
